Definições Fundamentais

Estudo das somas infinitas de números reais. Duas tarefas: determinar a natureza da série (converge ou diverge) e, em caso de convergência, calcular a soma.

Definição — Série e Soma Parcial Seja (aₙ)ₙ∈ℕ uma sucessão. A expressão a₁ + a₂ + a₃ + … chama-se série gerada por (aₙ), denotada Σaₙ. aₙ é o termo geral.
Sₙ = a₁ + a₂ + … + aₙ = Σ_{k=1}^n aₖ (sucessão das somas parciais)
Convergência A série Σaₙ é convergente se lim Sₙ (n→∞) existe e é finito. Nesse caso, a soma da série é:
Σ_{n=1}^∞ aₙ = lim_{n→∞} Sₙ
Se o limite não existe ou é infinito, a série é divergente.
Teorema — Resto de Ordem m Σaₙ é convergente ⟺ a série dos termos após m, Rₘ = Σ_{n=m+1}^∞ aₙ, é convergente.
Além disso, se Σaₙ converge, então lim_{m→∞} Rₘ = 0.
Consequência: a natureza de uma série não depende dos seus primeiros termos.
Condição Necessária de Convergência (1º Critério) Se Σaₙ é convergente, então lim aₙ = 0.
Forma contrapositiva (mais útil — "critério de divergência"):
lim aₙ ≠ 0 ou lim aₙ não existe ⟹ Σaₙ diverge
⚠ Atenção: se lim aₙ = 0, nada se pode concluir sobre a natureza da série!

Séries Geométricas e de Mengoli

Série Geométrica Gerada por uma progressão geométrica: a + ar + ar² + … = Σ_{n=0}^∞ ar^n, com a≠0 (1º termo) e r≠0 (razão).
Sₙ = na se r = 1 Sₙ = a(1-rⁿ)/(1-r) se r ≠ 1
Proposição — Convergência da Série Geométrica Σ_{n=1}^∞ ar^{n-1} converge ⟺ |r| < 1. Em caso de convergência:
Soma = a / (1 - r)
Série de Mengoli (Telescópica/Redutível) Σaₙ diz-se de Mengoli se aₙ se escreve como aₙ = uₙ - u_{n+p} ou aₙ = u_{n+p} - uₙ, com p ∈ ℕ.
Caso aₙ = uₙ - u_{n+p}: Sₙ = u₁ + … + uₚ - (u_{n+1} + … + u_{n+p}) Caso aₙ = u_{n+p} - uₙ: Sₙ = u_{n+1} + … + u_{n+p} - (u₁ + … + uₚ)
Calcular o limite de Sₙ quando n→∞ dá a soma (se existir).
Exemplo — Série de Mengoli Σ_{n=2}^∞ 2/(n²-1). Decompondo: 2/(n²-1) = 1/(n-1) - 1/(n+1), com p=2.
Sₙ = (1/1 + 1/2) - (1/(n) + 1/(n+1)) → 3/2 quando n→∞ Soma = 3/2

Propriedades Aritméticas e Séries de Termos Não Negativos

Propriedades Aritméticas Se Σaₙ = A e Σbₙ = B (convergentes), então:
Σ(aₙ + bₙ) = A + B (convergente) Σ(λaₙ) = λA ∀λ∈ℝ (convergente)
Se Σaₙ diverge e λ≠0, então Σ(λaₙ) diverge.
Se Σaₙ converge e Σbₙ diverge, então Σ(aₙ+bₙ) diverge.
⚠ Se ambas Σaₙ e Σbₙ divergem, Σ(aₙ+bₙ) pode convergir OU divergir (nada garantido).
Série de Termos Não Negativos Σaₙ tem termos não negativos se aₙ ≥ 0 para todo n.
Propriedade: a sucessão (Sₙ) é monótona crescente.
Teorema: Σaₙ converge ⟺ (Sₙ) é limitada superiormente.
Critério do Integral Seja Σaₙ série de termos não negativos e f: [1,∞[→ℝ decrescente com f(n) = aₙ. Então:
Σaₙ e ∫₁^∞ f(x)dx têm a mesma natureza
Série Harmónica/Dirichlet de Ordem p — RESULTADO FUNDAMENTAL
Σ_{n=1}^∞ 1/nᵖ converge ⟺ p > 1 (diverge se p ≤ 1)
(Para p=1: série harmónica, diverge. Decora este resultado — é usado como referência em quase todos os critérios de comparação!)
Critério da Comparação Se ∃n₀∈ℕ: 0 ≤ aₙ ≤ bₙ, ∀n≥n₀, então:
Σbₙ converge ⟹ Σaₙ converge Σaₙ diverge ⟹ Σbₙ diverge
⚠ Se Σbₙ diverge ou Σaₙ converge: nada se pode concluir.
Critério do Limite Sejam Σaₙ, Σbₙ com aₙ≥0, bₙ>0. Seja L = lim(aₙ/bₙ).
L ∈ ℝ⁺ (finito e positivo) ⟹ séries têm a MESMA natureza L = 0 e Σbₙ converge ⟹ Σaₙ converge L = +∞ e Σbₙ diverge ⟹ Σaₙ diverge
Dica: usar séries de Dirichlet (1/nᵖ) ou geométricas como Σbₙ de referência.
Exemplos Resolvidos Σ sin²(n)/n⁴: 0 ≤ sin²(n)/n⁴ ≤ 1/n⁴, e Σ1/n⁴ converge (p=4>1) → converge por comparação.
Σ 1/(n+√n³): comparar com 1/n^{3/2} (Critério do Limite, L=1) → p=3/2>1 → converge.
Σ sin(1/n): usar Critério do Limite com bₙ=1/n: lim[sin(1/n)/(1/n)]=1 → mesma natureza que Σ1/n → diverge.

Convergência Absoluta, D'Alembert e Cauchy

Convergência Simples e Absoluta Seja Σ|aₙ| a série dos módulos.
Σ|aₙ| converge ⟹ Σaₙ é ABSOLUTAMENTE convergente Σ|aₙ| diverge MAS Σaₙ converge ⟹ Σaₙ é SIMPLESMENTE convergente
Teorema: Toda série absolutamente convergente é convergente.
⚠ Se Σ|aₙ| diverge, nada se conclui sobre Σaₙ (pode convergir ou divergir).
Como Σ|aₙ| tem termos não negativos, podem usar-se todos os critérios da secção anterior!
Critério de D'Alembert (Quociente) Seja Σaₙ com aₙ≠0, e L = lim |a_{n+1}/aₙ|.
0 ≤ L < 1 ⟹ Σaₙ ABSOLUTAMENTE convergente L > 1 ⟹ Σaₙ DIVERGENTE L = 1 ⟹ inconclusivo (usar outro critério)
Critério de Cauchy (Raiz) Seja Σaₙ e L = lim ⁿ√|aₙ|.
0 ≤ L < 1 ⟹ Σaₙ ABSOLUTAMENTE convergente L > 1 ⟹ Σaₙ DIVERGENTE L = 1 ⟹ inconclusivo
Quando usar qual: D'Alembert é melhor quando há fatoriais ou produtos; Cauchy é melhor quando há potências de n (nⁿ, etc.)
Exemplos Típicos Σ 2ⁿn!/nⁿ (D'Alembert): L = lim[2^{n+1}(n+1)!/(n+1)^{n+1} · nⁿ/(2ⁿn!)] = lim[2nⁿ/(n+1)ⁿ] = 2/e < 1 → converge.
Σ (n/(n+1))^{n²} (Cauchy): L = lim (n/(n+1))ⁿ = lim 1/(1+1/n)ⁿ = 1/e < 1 → converge.
Σ (2n)!/n^n (D'Alembert): cresce mais rápido → L=+∞ → diverge.

Séries Alternadas — Critério de Leibniz

Série Alternada Série do tipo Σ(-1)ⁿaₙ ou Σ(-1)^{n+1}aₙ, com aₙ>0 ∀n.
Critério de Leibniz Seja Σ(-1)ⁿaₙ tal que:
  1. aₙ > 0, ∀n
  2. lim aₙ = 0
  3. (aₙ) é monótona decrescente
Então a série alternada é convergente.
Exemplo — Convergência Simples vs Absoluta Σ(-1)ⁿ/n: aₙ=1/n satisfaz Leibniz (decrescente, →0) → converge.
Mas Σ|(-1)ⁿ/n| = Σ1/n diverge (harmónica) → convergência SIMPLES (não absoluta).

Σ(-1)ⁿ/n²: Σ|(-1)ⁿ/n²| = Σ1/n² converge (p=2>1) → convergência ABSOLUTA.

Σ(-1)ⁿ/√(2n+1): aₙ=1/√(2n+1) decrescente, →0 → Leibniz aplica-se → converge.
Σ|aₙ| = Σ1/√(2n+1) compara-se com Σ1/√n (p=1/2≤1) → diverge → convergência SIMPLES.

Fluxograma de Decisão — Estudar a Natureza de uma Série

Estratégia Geral
  1. Verificar a condição necessária: lim aₙ ≠ 0 ⟹ diverge imediatamente
  2. É geométrica ou de Mengoli? Calcular Sₙ diretamente
  3. Termos não-negativos? Usar Integral, Comparação, ou Critério do Limite (comparar com Dirichlet 1/nᵖ ou geométrica)
  4. Tem fatoriais/potências de n na base e expoente? D'Alembert ou Cauchy
  5. É alternada? Verificar convergência absoluta primeiro (Σ|aₙ|); se não, tentar Leibniz para convergência simples

Séries de Potências — Conceitos

Séries cujos termos são potências de (x - c). Generalizam os polinómios para "polinómios de grau infinito" e permitem representar funções complicadas.

Definição — Série de Potências Série de potências centrada em c (de x-c):
Σ_{n=0}^∞ aₙ(x-c)ⁿ = a₀ + a₁(x-c) + a₂(x-c)² + …
aₙ são os coeficientes. Se c=0: série de potências centrada na origem. Convenção: a₀(x-c)⁰=a₀ mesmo se x=c (0⁰=1).
Domínio de Convergência D_c = conjunto de x∈ℝ para os quais a série converge. Como a série converge trivialmente em x=c, D_c ≠ ∅.
Teorema — Raio e Intervalo de Convergência Para qualquer série Σaₙ(x-c)ⁿ, ocorre exatamente uma de:
(i) converge SÓ em x=c (diverge se x≠c) → R = 0 (ii) converge absolutamente em TODO x∈ℝ → R = +∞ (iii) ∃R>0 único: converge absol. se x∈]c-R,c+R[ diverge se x∈]-∞,c-R[∪]c+R,+∞[
R = raio de convergência. I_c = ]c-R, c+R[ = intervalo de convergência.
⚠ Nos extremos do intervalo (x=c±R), a série pode convergir ou divergir — estudar caso a caso!
Cálculo do Raio de Convergência (via coeficientes) Se aₙ≠0 ∀n:
R = lim |aₙ| / |a_{n+1}| (se existir, via D'Alembert) R = 1 / lim ⁿ√|aₙ| (se existir, via Cauchy)
⚠ A série precisa estar escrita exatamente na forma Σaₙ(x-c)ⁿ para aplicar diretamente.
Exemplos de Domínios de Convergência
Σ xⁿ/n! → R=+∞, D_c = ℝ Σ (-1)^{n+1}/n · (x+1)ⁿ → R=1, D_c = ]-2, 0] (converge no extremo -2? não; em 0? sim, por Leibniz) Σ n!(x-2)ⁿ → R=0, D_c = {2} (só converge no centro)

Séries de Taylor e MacLaurin

Série de Taylor Se f admite derivadas finitas de todas as ordens em c, a série de potências
Σ_{n=0}^∞ f⁽ⁿ⁾(c)/n! · (x-c)ⁿ = f(c) + f'(c)(x-c) + f''(c)/2!·(x-c)² + …
chama-se série de Taylor de f em c. Se c=0: série de MacLaurin.
Função Analítica f é analítica em c se ∃r>0: para todo x∈]c-r,c+r[, a série de Taylor de f converge para f(x).
Exemplo de função NÃO analítica: f(x)=e^{-1/x²} (x≠0), f(0)=0. Apesar de ter todas as derivadas em 0 (todas nulas), a série de MacLaurin converge para a função NULA, não para f. Logo f não é analítica em 0.
Teorema — Convergência da Série de Taylor para f Para todo x∈I:
f(x) = Σ f⁽ⁿ⁾(c)/n! (x-c)ⁿ ⟺ lim Rₙᶜf(x) = 0 (Rₙᶜf é o resto de Lagrange)
Teorema (condição suficiente prática): se ∃M>0: |f⁽ⁿ⁾(x)| ≤ M, ∀x∈I, ∀n∈ℕ₀, então f(x) = Σf⁽ⁿ⁾(c)/n!(x-c)ⁿ, ∀x∈I.
(Aplica-se diretamente a sin, cos, exponencial, pois as suas derivadas são uniformemente limitadas.)

Polinómio de Taylor e Fórmula de Taylor com Resto de Lagrange

Sai em todos os testes: aproximar um valor (ln 2, ln 1.2, 1/√e, sen 3…), majorar o erro ou provar uma desigualdade. A série de Taylor é infinita; aqui corta-se na ordem n e controla-se o que se deitou fora.

Polinómio de Taylor de ordem n de f em c Se f tem derivadas até à ordem n em c:
Tₙᶜf(x) = f(c) + f'(c)(x−c) + f''(c)/2!·(x−c)² + … + f⁽ⁿ⁾(c)/n!·(x−c)ⁿ = Σ_{k=0}^{n} f⁽ᵏ⁾(c)/k! · (x−c)ᵏ
Se c = 0: polinómio de MacLaurin. Tₙᶜf é o único polinómio de grau ≤ n com as mesmas derivadas que f em c até à ordem n.
Teorema — Fórmula de Taylor com Resto de Lagrange Se f tem derivadas contínuas até à ordem n e f⁽ⁿ⁺¹⁾ existe num intervalo I que contém c e x, então existe ξ estritamente entre c e x tal que:
f(x) = Tₙᶜf(x) + Rₙᶜf(x), Rₙᶜf(x) = f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · (x−c)ⁿ⁺¹
O erro absoluto da aproximação f(x) ≈ Tₙᶜf(x) é |Rₙᶜf(x)|. (Para n = 0 é o Teorema de Lagrange do Cálculo I.)
Método — Majorar o erro (receita de exame)
  1. Calcular f, f', …, f⁽ⁿ⁾ em c e escrever Tₙᶜf. Calcular também a expressão de f⁽ⁿ⁺¹⁾(t).
  2. Escrever o resto: |Rₙ| = |f⁽ⁿ⁺¹⁾(ξ)|/(n+1)! · |x−c|ⁿ⁺¹, com ξ entre c e x.
  3. Majorar |f⁽ⁿ⁺¹⁾(ξ)| no intervalo entre c e x, usando monotonia: |sen|,|cos| ≤ 1; e^ξ < e^x se ξ < x; 1/ξᵏ < 1/cᵏ se ξ > c > 0.
  4. Concluir com desigualdade estrita (ξ nunca é extremo do intervalo).

  1. Reconhecer na série uma série de potências conhecida avaliada num ponto "óbvio" (x = 1, 1/3, 2π…).

Convergência Pontual e Uniforme

Distinção crucial entre convergência pontual (cada ponto converge independentemente) e convergência uniforme (toda a função converge "uniformemente" sem distorção).

Sucessão de Funções e Convergência Pontual (fₙ)ₙ∈ℕ sucessão de funções definidas em D. Converge pontualmente para f em D se, para CADA x∈D:
f(x) = lim_{n→∞} fₙ(x)
(Cada ponto x tem o seu próprio "ritmo" de convergência.)
Convergência Uniforme — Definição Mais Exigente (fₙ) converge uniformemente para f em D se a sucessão numérica Mₙ := sup_{x∈D}|fₙ(x)-f(x)| satisfaz lim Mₙ = 0.
Convergência uniforme: TODOS os pontos convergem "ao mesmo ritmo" (controlado por uma cota uniforme)
Implicação: convergência uniforme ⟹ convergência pontual (mas não o recíproco!).

Teorema — Propriedades Preservadas pela Convergência Uniforme Se (fₙ) são contínuas em [a,b] e convergem uniformemente para f, então:
  1. f é contínua em [a,b]
  2. f é integrável e ∫ₐᵇf(x)dx = lim∫ₐᵇfₙ(x)dx (integração termo a termo)
  3. Se fₙ têm derivadas contínuas e (fₙ') converge uniformemente, então f é diferenciável e f'(x) = lim fₙ'(x)
Uso prático invertido: se f (limite pontual) NÃO satisfaz uma destas propriedades (ex: é descontínua), a convergência NÃO é uniforme!

Série de Funções e Critério de Weierstrass

Série de Funções Σfₙ converge pontualmente/uniformemente em D se a sucessão das somas parciais (Sₙ) (com Sₙ=f₁+…+fₙ) converge pontualmente/uniformemente em D.
Critério de Weierstrass — CONDIÇÃO SUFICIENTE para Convergência Uniforme Sejam (fₙ) definidas em D e Σaₙ série numérica de termos não-negativos tal que:
|fₙ(x)| ≤ aₙ, ∀n∈ℕ, ∀x∈D
Se Σaₙ converge, então Σfₙ converge UNIFORMEMENTE em D.
Exemplo de Aplicação Σ1/(n²+x²) converge uniformemente em ℝ pois |1/(n²+x²)| ≤ 1/n² (para todo x) e Σ1/n² converge (Dirichlet p=2).
Logo, podemos integrar e derivar termo a termo:
∫₀¹ Σ1/(n²+x²) dx = Σ∫₀¹ 1/(n²+x²) dx = Σ (1/n)·arctan(1/n) (Σ1/(n²+x²))' = Σ(-2x)/(n²+x²)²
Propriedades das Séries Uniformemente Convergentes Se Σfₙ (funções contínuas em [a,b]) converge uniformemente com soma S, então:
(i) S é contínua; (ii) S integrável com integração termo a termo; (iii) se fₙ' existem e Σfₙ' converge uniformemente, então S é diferenciável com derivação termo a termo.

Séries de Potências — Convergência Uniforme

Teorema — Convergência Uniforme em Subintervalos Compactos Seja Σaₙ(x-c)ⁿ com raio R≠0. Então a série converge UNIFORMEMENTE em qualquer [a,b] ⊂ I_c = ]c-R,c+R[ (subintervalo fechado e limitado do intervalo de convergência).
Demonstração (esboço): Para x∈[a,b]⊂]-R,R[, |x|≤M=max{|a|,|b|}; logo |aₙxⁿ|≤|aₙ|Mⁿ, e como ΣaₙMⁿ converge absolutamente, Weierstrass garante convergência uniforme.
Teorema de Abel Se Σaₙ(x-c)ⁿ converge no ponto x=c+R (ou x=c-R), então converge uniformemente em [c, c+R] (ou [c-R, c]).
Propriedades da Função Soma (resultado central!) Seja f(x) = Σaₙ(x-c)ⁿ no intervalo de convergência I_c.
  1. f é contínua em todo I_c
  2. f é diferenciável: f'(x) = Σ n·aₙ(x-c)^{n-1}, ∀x∈I_c (derivação termo a termo)
  3. A função F(x) = Σ aₙ/(n+1)·(x-c)^{n+1} é a primitiva de f tal que F(c)=0
  4. f é integrável em qualquer [a,b]⊂I_c: ∫ₐᵇf(x)dx = Σ∫ₐᵇaₙ(x-c)ⁿdx
Teorema — Unicidade da Representação Se f(x) = Σaₙ(x-c)ⁿ em I_c, então f tem derivadas finitas de qualquer ordem e:
aₙ = f⁽ⁿ⁾(c)/n!, ∀n∈ℕ₀
Conclusão: qualquer série de potências que convirja para f é necessariamente a SUA série de Taylor!

Séries de Fourier

Série Trigonométrica Σ_{n=0}^∞ [aₙcos(nωx) + bₙsin(nωx)], com ω∈ℝ⁺. Se Σ|aₙ| e Σ|bₙ| convergem, a série é absoluta e uniformemente convergente em ℝ. A soma S(x), se existir, é periódica com período 2π/ω.
Função Periódica f é T-periódica se f(x+T)=f(x), ∀x, com T = menor tal valor. Qualquer função T-periódica pode converter-se numa 2π-periódica via F(x)=f(Tx/2π). Por isso estudamos apenas funções 2π-periódicas.
Coeficientes de Fourier Para f: ℝ→ℝ, 2π-periódica e integrável:
a₀ = (1/π) ∫_{-π}^{π} f(x) dx aₙ = (1/π) ∫_{-π}^{π} f(x)cos(nx) dx, n=1,2,… bₙ = (1/π) ∫_{-π}^{π} f(x)sin(nx) dx, n=1,2,…
Série de Fourier de f:
f(x) ~ a₀/2 + Σ_{n=1}^∞ [aₙcos(nx) + bₙsin(nx)]
Notação "~" porque a série pode não convergir para f. Pode calcular-se com qualquer intervalo de amplitude 2π (devido à periodicidade).
Simetrias — Atalhos Importantes
f ÍMPAR → série de Fourier é uma SÉRIE DE SENOS (aₙ=0, ∀n) f PAR → série de Fourier é uma SÉRIE DE COSSENOS (bₙ=0, ∀n)
Extensões Periódicas — Extensão Par e Ímpar Para f: [0,π]→ℝ integrável:
Extensão ÍMPAR f_i: [-π,π]→ℝ f_i(x) = -f(-x) se -π≤x<0 f_i(x) = f(x) se 0≤x≤π → série de Fourier de f_i é série de SENOS Extensão PAR f_p: [-π,π]→ℝ f_p(x) = f(-x) se -π≤x<0 f_p(x) = f(x) se 0≤x≤π → série de Fourier de f_p é série de COSSENOS
Exemplos Clássicos de Séries de Fourier f(x)=|x|, 2π-periódica:
f(x) ~ π/2 - (4/π) Σ_{n=1}^∞ cos[(2n-1)x]/(2n-1)²
g(x): 0 em [-π,0[, π em [0,π[, 2π-periódica:
g(x) ~ π/2 + Σ_{n=1}^∞ (2/(2n-1)) sin[(2n-1)x]
Extensão par e ímpar de f(x)=x em [0,π]:
Extensão par (|x|): π/2 - (4/π)Σcos[(2n-1)x]/(2n-1)² Extensão ímpar (x): 2·Σ(-1)^{n+1} sin(nx)/n
Função Seccionalmente Contínua / Diferenciável f é seccionalmente contínua em [a,b] se existe partição {a₀,…,aₙ} tal que f é contínua em cada subintervalo aberto e existem (finitos) os limites laterais em cada ponto de partição.
f é seccionalmente diferenciável se f e f' são seccionalmente contínuas.
Teorema de Dirichlet — Convergência Pontual da Série de Fourier Se f: ℝ→ℝ é 2π-periódica e seccionalmente diferenciável, então a série de Fourier de f converge em cada c∈ℝ para:
[f(c⁺) + f(c⁻)] / 2 (média dos limites laterais)
Em particular:
Se x é ponto de continuidade de f: S(x) = f(x) Se x não é ponto de continuidade: S(x) = [f(x⁺)+f(x⁻)]/2
S é periódica com período 2π.
Aplicação — Calcular Somas de Séries Numéricas! Usando f(x)=|x| e Dirichlet com x=0 (f contínua):
0 = π/2 - (4/π)Σ1/(2n-1)² ⟹ Σ_{n=1}^∞ 1/(2n-1)² = π²/8 Usando a decomposição Σ1/n² = Σ1/(2n)² + Σ1/(2n-1)²: Σ1/n² = (1/4)Σ1/n² + π²/8 ⟹ Σ1/n² = π²/6 (problema de Basileia!)
Usando g(x) com x=π/2:
π = π/2 + Σ(2/(2n-1))sin[(2n-1)π/2] ⟹ Σ_{n=1}^∞ (-1)^{n+1}/(2n-1) = π/4 (série de Leibniz para π!)

Distância Euclidiana Para X=(x₁,…,xₙ), Y=(y₁,…,yₙ):
d(X,Y) = √[(x₁-y₁)² + … + (xₙ-yₙ)²]

Limites e Continuidade

Limite de uma Função (via sucessões) Seja A ponto de acumulação de D. lim_{X→A} f(X) = ℓ se para QUALQUER sucessão (Xₙ) em D\{A} com Xₙ→A, tem-se f(Xₙ)→ℓ.
Crucial: isto deve valer para TODAS as sucessões/direções de aproximação!
Limite Segundo um Conjunto (ferramenta para provar NÃO existência) Para R⊆D com A ponto de acumulação de R: lim_{X→A, X∈R} f(X) = lim_{X→A} f|_R(X).
Casos especiais: limites direcionais (segundo retas y=mx).
Critérios de Não-Existência de Limite — FERRAMENTA MAIS USADA EM EXAME!
  1. Se ∃R⊆D tal que lim_{X→A,X∈R}f(X) NÃO existe → lim_{X→A}f(X) NÃO existe
  2. Se ∃R₁,R₂⊆D com lim_{X→A,X∈R₁}f(X) ≠ lim_{X→A,X∈R₂}f(X) → o limite NÃO existe
Estratégia padrão: testar y=0, x=0, e y=mx (família de retas) — se derem valores diferentes, o limite não existe.
Exemplo Clássico — xy/(x²+y²) em (0,0)
R₁={y=0}: lim 0/x² = 0 R₂={x=0}: lim 0/y² = 0 (iguais até agora!) R_m={y=mx}: lim (x·mx)/(x²+m²x²) = m/(1+m²) (varia com m!) ⟹ limite NÃO existe (diferentes retas dão valores diferentes)
Exemplo — Limite que EXISTE: x²y/(x²+y²) em (0,0) Para qualquer sucessão (xₙ,yₙ)→(0,0): |x²y/(x²+y²)| = |y|·x²/(x²+y²) ≤ |y| → 0.
(Produto de infinitésimo |y|→0 por função limitada x²/(x²+y²)≤1.) Limite = 0.
Propriedades Algébricas dos Limites Se lim f(X)=ℓ₁ e lim g(X)=ℓ₂ (X→A):
lim(f+g)=ℓ₁+ℓ₂; lim(λf)=λℓ₁; lim(fg)=ℓ₁ℓ₂; lim(f/g)=ℓ₁/ℓ₂ (se ℓ₂≠0)
Duas Proposições Úteis para Cálculo de Limites Infinitésimo × função limitada: Se lim f(X)=0 e g é limitada perto de A, então lim f(X)g(X)=0.
Mudança de variável: Se f(X)=g(u(X)) com lim u(X)=c e lim_{z→c} g(z)=ℓ (g contínua ou não-definida em c), então lim f(X) = ℓ.
Exemplo — Mudança de Variável lim_{(x,y)→(1,1)} (e^{x-y}-1)/(y-x). Seja u=x-y; quando (x,y)→(1,1), u→0.
(e^u-1)/(-u) = -(e^u-1)/u → -1 (limite notável conhecido em Cálc. I)
Continuidade f é contínua em P (ponto de acumulação de D) se lim_{X→P}f(X) = f(P). Se P é isolado, f é automaticamente contínua aí.
Propriedades: somas, produtos, λf, quociente (g(P)≠0) e composição com função contínua preservam continuidade.

Limites — Para Além das Retas: Curvas e Coordenadas Polares

Retas não chegam — usar curvas y = mx², x = y², … Se todas as retas y = mx dão o mesmo valor, o limite ainda pode não existir. Escolhe-se uma curva que "equilibre" os graus do numerador e do denominador.
f(x,y) = x²y/(x⁴ + y²) em (0,0) (Ficha 3-I, 6) Retas y = mx: x²·mx/(x⁴ + m²x²) = mx/(x² + m²) → 0 (para todo m) Parábolas y = mx²: x²·mx²/(x⁴ + m²x⁴) = m/(1 + m²) (depende de m!) ⟹ o limite NÃO existe.
Truque: em x⁴ + y², x tem "peso" 1 e y "peso" 2, por isso testa-se y = mx².
Exemplo — Caminhos que não são eixos
lim x⁴/(y⁴ + (y−x)²) em (0,0) (Ficha 3-I, 5e) x = 0: 0/y⁴ = 0 y = x: x⁴/(x⁴ + 0) = 1 ⟹ limites diferentes, NÃO existe
Escolhe-se y = x porque anula o termo (y−x)² do denominador.
Coordenadas Polares — para provar que o limite EXISTE Em (0,0) faz-se x = r cos θ, y = r sen θ (r → 0⁺). Se
|f(r cos θ, r sen θ) − ℓ| ≤ g(r) com g(r) → 0 (independente de θ)
então lim f = ℓ. ⚠ A majoração tem de ser uniforme em θ; um limite que depende de θ prova a não existência.
3x²y/(x² + 2y²): |3r³cos²θ senθ| / (r²(cos²θ + 2sen²θ)) ≤ 3r³/r² = 3r → 0 (porque cos²θ + 2sen²θ ≥ 1) ⟹ limite = 0 (Ficha 3-I, 5d) (x⁴ − 4y⁴)/(2x² + 4y²) = (x² − 2y²)(x² + 2y²)/[2(x² + 2y²)] = (x² − 2y²)/2 → 0 (fatorizar!)
Estratégia completa para lim em (0,0)
  1. Tentar substituir (se o denominador não se anula, é contínua: acabou).
  2. Simplificar/fatorizar (diferença de quadrados, conjugado).
  3. Testar x = 0, y = 0, y = mx. Se der valores diferentes ⟹ não existe.
  4. Se todas iguais a ℓ: testar curvas (y = mx², x = my², y = x se houver (y−x)).
  5. Suspeita de que existe: provar com infinitésimo × limitada ou polares.
Funções definidas por ramos (continuidade) Num ponto da linha onde muda a fórmula (ex.: x = 0 no T2 2023/24), calcula-se o limite usando os dois ramos: os pontos com x ≠ 0 usam a 1.ª fórmula e os da reta x = 0 usam a 2.ª. É contínua só se ambos tenderem para o valor da função no ponto.

Derivação Parcial e Derivadas Direcionais

Derivada Parcial Para f: D⊆ℝ²→ℝ e (a,b)∈int(D):
∂f/∂x (a,b) = lim_{h→0} [f(a+h,b) - f(a,b)] / h ∂f/∂y (a,b) = lim_{h→0} [f(a,b+h) - f(a,b)] / h
Na prática: derivar em ordem a x tratando y como constante (e vice-versa).
Interpretação Geométrica ∂f/∂x(a,b) é o declive da reta tangente à curva de interseção do gráfico de f com o plano y=b, no ponto (a,b,f(a,b)).
Vetor diretor desta reta: (1, 0, ∂f/∂x(a,b)). Analogamente para ∂f/∂y com (0,1,∂f/∂y(a,b)).
Derivadas Parciais de Ordem Superior
∂²f/∂x² = ∂/∂x(∂f/∂x) ∂²f/∂y² = ∂/∂y(∂f/∂y) ∂²f/∂x∂y = ∂/∂x(∂f/∂y) [derivadas MISTAS] ∂²f/∂y∂x = ∂/∂y(∂f/∂x)
⚠ As derivadas mistas podem ser DIFERENTES em geral!
Teorema de Schwarz (Igualdade das Derivadas Mistas) Se existem ∂f/∂x, ∂f/∂y, ∂²f/∂x∂y numa bola aberta em (a,b) e ∂²f/∂x∂y é contínua em (a,b), então existe ∂²f/∂y∂x(a,b) e:
∂²f/∂y∂x (a,b) = ∂²f/∂x∂y (a,b)
Corolário prático: se f∈C²(D) (classe C², i.e. todas as derivadas até ordem 2 são contínuas), então as derivadas mistas são SEMPRE iguais.
Contra-Exemplo — Derivadas Mistas Diferentes f(x,y) = xy(x²-y²)/(x²+y²) se (x,y)≠(0,0), f(0,0)=0.
∂²f/∂y∂x (0,0) = -1 ≠ ∂²f/∂x∂y (0,0) = 1
(Mostra que sem a hipótese de continuidade de Schwarz, podem diferir.)
Derivada Direcional Para U vetor UNITÁRIO de ℝⁿ:
D_U f(P) = lim_{h→0} [f(P+hU) - f(P)] / h
As derivadas parciais são casos particulares com U=(1,0) ou (0,1).
⚠ Existir todas as derivadas direcionais NÃO garante continuidade! Exemplo: f(x,y)=xy²/(x²+y⁴) (e f(0,0)=0) não é contínua em (0,0), mas todas as derivadas direcionais existem aí (com valor u₂²/u₁ se u₁≠0, e 0 se u₁=0).

Diferenciabilidade e Planos Tangentes

Função Diferenciável (n=2) f é diferenciável em (a,b) se existem ∂f/∂x(a,b), ∂f/∂y(a,b) e:
lim_{(h,k)→(0,0)} [f(a+h,b+k) - f(a,b) - ∂f/∂x(a,b)·h - ∂f/∂y(a,b)·k] / √(h²+k²) = 0
Isto garante que f é "bem aproximada" pelo plano tangente (linearização).
Condição SUFICIENTE de Diferenciabilidade Se ∂f/∂x e ∂f/∂y existem numa bola aberta centrada em P, e PELO MENOS UMA é contínua em P, então f é diferenciável em P.
Corolário: Se f é de classe C¹ numa bola aberta em P, então f é diferenciável em P (e em toda a bola).
Condição NECESSÁRIA de Diferenciabilidade Se f é diferenciável em P, então f é CONTÍNUA em P.
Forma contrapositiva (mais útil): se f NÃO é contínua em P, então f NÃO é diferenciável em P.
Exemplos Famosos de (Não-)Diferenciabilidade f(x,y)=√(x²+y²): diferenciável em todo (a,b)≠(0,0); NÃO diferenciável em (0,0) (a função tem um "bico" cónico).
f(x,y)=x²/(x²+y²), f(0,0)=0: NÃO contínua em (0,0) (limites direcionais distintos) ⟹ NÃO diferenciável aí.
Plano Tangente e Vetor Normal Para f diferenciável em (a,b), o plano tangente ao gráfico em (a,b,f(a,b)):
z = f(a,b) + ∂f/∂x(a,b)·(x-a) + ∂f/∂y(a,b)·(y-b)
Vetor normal: N = (-∂f/∂x(a,b), -∂f/∂y(a,b), 1)
Reta normal: (x,y,z) = (a,b,f(a,b)) + λN, λ∈ℝ
Exemplo Completo — Plano Tangente f(x,y)=4-x²-y² em P=(1,-1,2). ∂f/∂x=-2x, ∂f/∂y=-2y, ambas contínuas em ℝ² ⟹ f diferenciável em ℝ².
Plano tangente: z = 2 + (-2)(x-1) + 2(y+1) ⟺ 2x - 2y + z = 6 Reta normal: (x,y,z) = (1,-1,2) + λ(2,-2,1)
Vetor Gradiente
∇f(P) = (∂f/∂x₁(P), ∂f/∂x₂(P), …, ∂f/∂xₙ(P))

Definições — Teorema de Weierstrass e Fermat

Como classificar máximos, mínimos e pontos de sela usando derivadas parciais e a matriz Hessiana. Tema de exame quase garantido!

Extremos Locais e Globais
P maximizante LOCAL: ∃Bᵣ(P): ∀X∈Bᵣ(P)∩D, f(X)≤f(P) P maximizante GLOBAL: ∀X∈D, f(X)≤f(P) (análogo para minimizante, trocando ≤ por ≥)
Máximos/mínimos = extremos; pontos onde ocorrem = extremantes.
Teorema de Weierstrass — Existência de Extremos Globais Se f:D⊆ℝⁿ→ℝ é contínua e D é COMPACTO (fechado e limitado), então f admite máximo e mínimo globais em D.
⚠ Sem compacidade, extremos globais podem não existir (e.g. f(x,y)=4-x²-y² em ℝ² tem máximo mas não mínimo).
Teorema de Fermat — Condição NECESSÁRIA para Extremo Local Se P∈int(D), f tem derivadas parciais de 1ª ordem em P, e P é extremante local, então:
∇f(P) = (0, 0, …, 0)
Ponto crítico: P∈int(D) com ∇f(P)=0̄.
⚠ Cuidado: nem todo ponto crítico é extremante! Pode ser ponto de sela. Também: extremante interior pode ocorrer onde alguma derivada parcial NÃO existe (não é necessariamente ponto crítico nesse caso).
Exemplo — Ponto de Sela f(x,y)=x²-y². ∇f(0,0)=(0,0) → ponto crítico. Mas ao longo de y=0: f(x,0)=x²≥0 (parece mínimo); ao longo de x=0: f(0,y)=-y²≤0 (parece máximo). Logo (0,0) NÃO é extremante — é ponto de sela.

Matriz Hessiana Para f de classe C² em int(D), P∈int(D):
Hf(P) = [ ∂²f/∂x₁²(P) ∂²f/∂x₁∂x₂(P) … ∂²f/∂x₁∂xₙ(P) ] [ ∂²f/∂x₂∂x₁(P) ∂²f/∂x₂²(P) … ∂²f/∂x₂∂xₙ(P) ] [ ⋮ ⋮ ⋱ ⋮ ] [ ∂²f/∂xₙ∂x₁(P) ∂²f/∂xₙ∂x₂(P) … ∂²f/∂xₙ²(P) ]
Matriz SIMÉTRICA (por Schwarz, se f∈C²). O Hessiano = determinante de Hf(P).
Cadeia de Menores Principais Líderes Para A=[aᵢⱼ] matriz n×n:
M₁ = |a₁₁| M₂ = det [[a₁₁,a₁₂],[a₂₁,a₂₂]] … Mₖ = determinante do bloco superior-esquerdo k×k … Mₙ = det(A)
Teste da Hessiana — Caso Geral (n variáveis) Seja P ponto crítico, f∈C², det(Hf(P))≠0 (Mₙ(P)≠0):
Mₖ(P) > 0, ∀k=1,…,n (todos positivos) → P é MINIMIZANTE local Mₖ(P) alternado: M₁<0, M₂>0, M₃<0, … → P é MAXIMIZANTE local Caso contrário (sem ser nenhum dos padrões acima) → P é PONTO DE SELA
Se det(Hf(P))=0: teste INCONCLUSIVO (recorrer à definição).
Teste da Hessiana — Caso n=2 (versão simplificada, MAIS USADA) P ponto crítico, det(Hf(P))≠0:
det(Hf(P)) > 0 e ∂²f/∂x²(P) > 0 → MINIMIZANTE local det(Hf(P)) > 0 e ∂²f/∂x²(P) < 0 → MAXIMIZANTE local det(Hf(P)) < 0 → PONTO DE SELA det(Hf(P)) = 0 → inconclusivo

Cálculo de Extremos Globais em Compactos

Procedimento Completo (4 Passos)
  1. Determinar, no INTERIOR de D, os pontos críticos de f (∇f=0̄)
  2. Determinar, no interior de D, pontos onde alguma derivada parcial NÃO existe
  3. Determinar os candidatos a extremantes da restrição de f à FRONTEIRA de D (frequentemente via parametrização)
  4. Calcular f em TODOS os pontos obtidos (1-3): o MAIOR valor é o máximo global, o MENOR é o mínimo global
Exemplo Completo — f(x,y)=x²+y²-x-y+1, D={x²+y²≤1}
Passo 1 (interior): ∇f=(2x-1,2y-1)=(0,0) → P₁=(1/2,1/2). Único ponto crítico interior. Passo 2: f tem derivadas parciais em todo o interior → nada a acrescentar. Passo 3 (fronteira x²+y²=1): parametrizar x=cosθ, y=sinθ, θ∈[0,2π] g(θ) = f(cosθ,sinθ) = 2 - cosθ - sinθ g'(θ) = sinθ - cosθ = 0 → θ=π/4 ou θ=5π/4 Candidatos: P₂=(√2/2,√2/2), P₃=(-√2/2,-√2/2), e extremos do parâmetro θ=0, θ=2π (mesmo ponto P₄=(1,0)) Passo 4: f(P₁)=1/2, f(P₂)=2-√2, f(P₃)=2+√2, f(P₄)=1 → MÁXIMO global = 2+√2 (em P₃) → MÍNIMO global = 1/2 (em P₁)

Extremos Condicionados — Multiplicadores de Lagrange

Extremo Condicionado Dados f:D→ℝ, g:D→ℝ, e C={(x,y)∈D : g(x,y)=0}, os extremos da restrição f|_C dizem-se extremos condicionados de f sujeitos à restrição g(x,y)=0.
min/max f(x,y) s.a. g(x,y) = 0
Teorema dos Multiplicadores de Lagrange D aberto, f,g∈C¹(D), C={g=0}. Se P∈C é extremante de f|_C e ∇g(P)≠(0,0), então existe λ∈ℝ (multiplicador de Lagrange) tal que:
∇f(P) = λ∇g(P)
Geometricamente: nos extremos condicionados, os gradientes de f e g são COLINEARES (as curvas de nível de f são tangentes à restrição C).
Método dos Multiplicadores de Lagrange — Procedimento
  1. Resolver o sistema {∇f(x,y)=λ∇g(x,y), g(x,y)=0}, admitindo ∇g≠(0,0)
  2. Verificar separadamente se ∇g(x₀,y₀)=(0,0) em algum ponto de C — esse ponto pode também ser extremante
  3. Estudar a natureza dos pontos obtidos (geralmente via Weierstrass, se C é compacto, ou comparando valores de f)
Exemplo Completo — Lagrange min/max f(x,y)=x²+y²-x-y+1 s.a. g(x,y)=x²+y²-1=0.
∂f/∂x=2x-1, ∂f/∂y=2y-1, ∂g/∂x=2x, ∂g/∂y=2y Sistema: { 2x-1=λ2x, 2y-1=λ2y, x²+y²=1 } Resolvendo: x=y=√2/2, λ=1-√2/2 OU x=y=-√2/2, λ=1+√2/2 Candidatos: P=(√2/2,√2/2), Q=(-√2/2,-√2/2) Como a restrição é compacta e f contínua, Weierstrass garante que P,Q são os extremantes: f(P) = 2-√2 → MÍNIMO condicionado f(Q) = 2+√2 → MÁXIMO condicionado
(Note: coincide com o resultado obtido via parametrização da fronteira no exemplo anterior — duas formas diferentes do mesmo problema!)
