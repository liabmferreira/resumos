def isleap(y):
    # bissexto: divisível por 4 e não por 100, ou divisível por 400
    return (y % 4 == 0 and y % 100 != 0) or y % 400 == 0

def intersect(a1, b1, a2, b2):
    # intervalos [a1,b1] e [a2,b2] intersetam-se?

3 · Funções e parâmetros

def pol(a, b, c, x):          # parâmetros
    return a*x**2 + b*x + c   # valor devolvido

pol(1, 2, 3, 1)               # 6
def f(x, y=10): return x + y  # valor por omissão

  • Uma função sem return (ou com return sozinho) devolve None.
  • return a, b devolve um tuplo; recebe-se com x, y = f().
  • Variáveis criadas dentro da função são locais: desaparecem quando a função termina.
  • return termina logo a função; código depois dele não corre.

Passagem de argumentos: mutáveis e imutáveis

O parâmetro recebe uma referência para o mesmo objeto. O que acontece depende do tipo e do que fazes dentro da função.

Alterar o objeto (mutável)

def changeme(l):
    l.append(4)

m = [1, 2, 3]
changeme(m)
print(m)   # [1, 2, 3, 4]

A lista original muda: os dois nomes apontam para o mesmo "papagaio" (como diz o professor).

Reatribuir o nome

def changeme(l):
    l = [1, 2, 3, 4]

m = [10, 20, 30]
changeme(m)
print(m)   # [10, 20, 30]

A lista original não muda: l passou a apontar para outra lista.

Com int, str, tuple (imutáveis) nunca consegues alterar o original dentro da função; tens de devolver o novo valor (a = increment(a)).

Cuidado

l2 = l não copia: é a mesma lista com dois nomes. Para copiar usa l.copy(), l[:] ou list(l).

5 · Recursividade

Uma função recursiva chama-se a si própria com um problema mais pequeno, até chegar a um caso base que se resolve diretamente.

Receita para escrever uma função recursiva
  1. Caso base: qual é o caso mais simples, com resposta imediata? (n == 0, lista vazia, string de 1 letra, número com 1 dígito)
  2. Passo recursivo: como reduzo o problema? (n-1, n//10, lista sem o primeiro elemento)
  3. Combinação: como junto o resultado da chamada ao que falta? (multiplicar por n, somar 1, concatenar)
  4. Confirma que todas as chamadas chegam ao caso base. Senão: RecursionError.
def fact(n):
    if n == 0:                 # caso base: 0! = 1
        return 1
    return n * fact(n - 1)

def fib(n):
    if n <= 1:                 # fib(0)=0, fib(1)=1
        return n
    return fib(n - 1) + fib(n - 2)

def soma_recursiva(n):         # 1 + 2 + ... + n
    if n <= 0:
        return 0
    return n + soma_recursiva(n - 1)

def contar_digitos(n):
    n = abs(n)                 # ignorar o sinal
    if n < 10:                 # caso base: 1 dígito
        return 1
    return 1 + contar_digitos(n // 10)

def soma_lista(l):
    if l == []:
        return 0
    return l[0] + soma_lista(l[1:])
Pergunta do teste: caso base do fatorial

Sabendo que fact(0) = 1, o caso base mais apropriado é n == 0. n == 1 falha para fact(0) (nunca pára: 0, -1, -2...); n >= 0 seria verdadeiro logo à primeira e nunca recursaria.

Rastrear uma chamada

fact(3) = 3 * fact(2)
        = 3 * (2 * fact(1))
        = 3 * (2 * (1 * fact(0)))
        = 3 * (2 * (1 * 1)) = 6

9 · Compreensões (list, set, dict)

Forma compacta de construir uma coleção a partir de outra. É dos temas que mais sai no teste.

Equivalência a decorar 
res = [expr for x in col if cond]

res = []
for x in col:
    if cond:
        res.append(expr)
  • [...] lista; {...} conjunto; {k: v ...} dicionário; (...) gerador (só dentro de sum, max, etc.).
  • if no fim filtra: [x for x in l if x > 0].
  • if ... else no início transforma e tem de ter else: [x if x > 0 else 0 for x in l].
  • Vários for leem-se da esquerda para a direita, como ciclos encaixados (o primeiro é o de fora).

10 · Lambda, map, filter, reduce

Uma lambda é uma função sem nome, com uma só expressão (sem return, sem if em bloco, só a forma a if c else b).

soma = lambda x, y: x + y          # igual a def soma(x, y): return x + y
soma(3, 4)                         # 7
(lambda x, y, z=3: x + y + z)(1, 2)    # 6
intervalo = lambda a, b: (b, a) if a > b else (a, b)
Pergunta do teste: lambda equivalente 
def pak(a, b):
    p = a*b
    return p, a
# equivalente:
pak = lambda a,b: (a*b, a)

Preenches a,b antes dos dois pontos e a*b, a no tuplo. Não há variável p: numa lambda escreve-se diretamente a expressão.

11 · Ordenação

sorted(l)l.sort()
Altera l?nãosim
Devolvenova listaNone
Funciona emqualquer coleção (string, tuplo, dicionário...)só listas

Ambos aceitam reverse=True e key=função. A key recebe um elemento e devolve o valor pelo qual se ordena.

sorted(["Harry", "Suzy", "Al"])              # ['Al', 'Harry', 'Suzy']
sorted(words, key=len)                       # pelo comprimento
sorted(names, key=str.lower)                 # ignorando maiúsculas
sorted(alunos, key=lambda t: t[2])           # pelo 3.º campo do tuplo
sorted(l, key=lambda i: i[0] + i[1])         # por uma conta
sorted(d.items(), key=lambda kv: kv[1], reverse=True)   # dicionário por valor, decrescente
sorted(l, key=lambda t: (-t[1], t[0]))      # 2 critérios: valor desc., depois nome asc.

A ordenação é estável: elementos com a mesma chave mantêm a ordem original. Sem key, maiúsculas vêm antes de minúsculas: sorted(["Mario", "anabela"]) dá ['Mario', 'anabela'].

Pergunta do teste

Para lst = [(4, "corpo"), (7, "alma"), ...] ordenada pelo comprimento da palavra: key=lambda t: len(t[1]). key=len mediria o tuplo (sempre 2); key=lambda t: t[0] ordena pelo número.

Algoritmos clássicos

def selection_sort(l):
    l = l.copy()
    for i in range(len(l)):
        m = i
        for j in range(i + 1, len(l)):     # procurar o mínimo do resto
            if l[j] < l[m]:
                m = j
        l[i], l[m] = l[m], l[i]            # pô-lo na posição i
    return l

def insertion_sort(l):
    l = l.copy()
    for i in range(1, len(l)):
        x, j = l[i], i - 1
        while j >= 0 and l[j] > x:          # empurrar os maiores para a direita
            l[j + 1] = l[j]
            j -= 1
        l[j + 1] = x                       # inserir no sítio certo
    return l

12 · Pesquisa

Já existem: x in l (True/False) e l.index(x) (posição, erro se não existir).

def pesquisa_linear(l, x):          # funciona em qualquer lista
    for i in range(len(l)):
        if l[i] == x:
            return i
    return -1                      # ou None

def pesquisa_binaria(l, x):         # SÓ em listas ORDENADAS
    lo, hi = 0, len(l) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if l[mid] == x:
            return mid
        elif l[mid] < x:
            lo = mid + 1           # está à direita
        else:
            hi = mid - 1           # está à esquerda
    return -1

A pesquisa binária corta o problema a meio a cada passo: em 1 milhão de elementos precisa de ~20 comparações em vez de 1 milhão.

Módulo bisect (lista ordenada li = [1, 3, 4, 4, 4, 6, 7]): bisect.bisect_left(li, 4) dá 2 (primeira posição onde inserir 4); bisect.bisect(li, 4) (= bisect_right) dá 5 (última). x existe se k < len(li) and li[k] == x com k = bisect_left(li, x).

Exercícios práticos resolvidos

Os 7 exercícios da folha de preparação, com soluções curtas e testadas. A do exercício 1 é mais simples e mais correta do que a resolução que circula: usa o mínimo das divisões inteiras.

1 · Dicionários: quantos bolos o Peter consegue fazer
def cakes(recipe, available):
    # para cada ingrediente: quantas vezes cabe a quantidade da receita no que há
    # ingrediente em falta conta como 0, por isso usamos get(..., 0)
    return min(available.get(ing, 0) // qt for ing, qt in recipe.items())

print(cakes({"flour": 500, "sugar": 200, "eggs": 1},
            {"flour": 1200, "sugar": 1200, "eggs": 5, "milk": 200}))   # 2
print(cakes({"apples": 3, "flour": 300, "sugar": 150, "milk": 100, "oil": 100},
            {"sugar": 500, "flour": 2000, "milk": 2000}))              # 0
2 · Conjuntos: elementos que aparecem exatamente uma vez
def elementos_unicos(listas):
    cont = {}
    for l in listas:
        for x in l:
            cont[x] = cont.get(x, 0) + 1
    return {x for x, n in cont.items() if n == 1}

print(elementos_unicos([[1, 2, 3], [3, 4, 5], [5, 6, 7]]))   # {1, 2, 4, 6, 7}
3 · Lambda: ordenar (nome, idade) pela idade
sorted([("João", 25), ("Ana", 20), ("Miguel", 30)], key=lambda p: p[1])
# [('Ana', 20), ('João', 25), ('Miguel', 30)]
4 · Lambda: inverter e pôr em maiúsculas as strings de tamanho ímpar
list(map(lambda s: s[::-1].upper() if len(s) % 2 else s,
         ["Python", "is", "fun", "cool", "awesome"]))
# ['Python', 'is', 'NUF', 'cool', 'EMOSEWA']
5 · Recursividade: soma de 1 até n
def soma_recursiva(n):
    if n <= 0:
        return 0
    return n + soma_recursiva(n - 1)    # soma_recursiva(5) = 15
6 · Recursividade: contar dígitos
def contar_digitos_recursivo(n):
    n = abs(n)
    if n < 10:
        return 1
    return 1 + contar_digitos_recursivo(n // 10)   # 12345 -> 5, -54321 -> 5
7 · Recursividade: permutações sem repetidos
def permutacoes_recursivas(s):
    if len(s) <= 1:
        return {s}
    res = set()                                  # set elimina repetidos ("aab")
    for i, letra in enumerate(s):
        resto = s[:i] + s[i+1:]                  # a string sem a letra i
        for p in permutacoes_recursivas(resto):
            res.add(letra + p)
    return res

print(sorted(permutacoes_recursivas("aab")))   # ['aab', 'aba', 'baa']

Armadilhas de leitura de código

  • input() devolve sempre uma string.
  • Fatias excluem o fim: l[2:4] tem 2 elementos.
  • append, sort, reverse devolvem None.
  • / dá float, mesmo em 4/2 (dá 2.0).
  • print(a, b) põe espaço entre eles; end="," muda o fim.

Armadilhas com coleções

  • x in dict procura chaves, não valores.
  • {} é dicionário vazio, não conjunto.
  • l2 = l não copia a lista.
  • Uma função pode alterar uma lista recebida.
  • map/filter precisam de list() para mostrar valores.
