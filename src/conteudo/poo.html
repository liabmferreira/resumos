Referências (objetos, arrays, String) valem null por omissão. Variáveis locais não têm valor por omissão: usar sem inicializar dá erro de compilação. Constantes: final, em MAIÚSCULAS (SPEED_LIMIT). Classes em PascalCase, métodos e variáveis em camelCase.

2 · Classes e objetos

Uma classe é o molde (atributos + métodos); um objeto é uma instância criada com new. Uma classe pode ter atributos, métodos, construtores, blocos static e classes internas.

public class Book {
    private static int nextId = 1;     // de CLASSE: partilhado por todos os objetos
    private final int id;              // final: só se atribui uma vez (no construtor)
    private String title;              // private: encapsulamento
    private double price;

    public Book(String title, double price) {   // construtor
        this.id = nextId++;            // id automático e incremental
        this.title = title;            // this distingue atributo de parâmetro
        setPrice(price);
    }

    public Book(String title) {        // sobrecarga (overloading): mesmo nome, parâmetros diferentes
        this(title, 0.0);              // chama o outro construtor (tem de ser a 1.ª linha)
    }

    public int getId() { return id; }
    public String getTitle() { return title; }
    public double getPrice() { return price; }
    public void setPrice(double price) {
        if (price < 0) throw new IllegalArgumentException("Preço negativo");
        this.price = price;            // os setters validam: é para isso que existe encapsulamento
    }

    @Override
    public String toString() {         // sem isto, println mostra "Book@33909752"
        return String.format("Book #%d: %s (%.2f €)", id, title, price);
    }
}

Regras que saem em verdadeiro/falso
  • Se não definires nenhum construtor, o compilador cria um construtor por omissão sem argumentos. Se definires um qualquer, deixa de existir.
  • Atributos e métodos static pertencem à classe: chamam-se Classe.metodo(), mesmo sem existirem objetos. Um método static não pode usar this nem atributos de instância.
  • final: variável não muda; método não pode ser reescrito; classe não pode ter subclasses.
  • a == b compara referências (é o mesmo objeto?). a.equals(b) compara o conteúdo, se a classe o redefinir.
  • Objetos da mesma classe têm o mesmo comportamento mas guardam dados diferentes.

equals e hashCode

Se redefinires equals, redefine também hashCode: o HashSet e o HashMap usam os dois. Objetos iguais têm de ter o mesmo hashCode.

@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (o == null || getClass() != o.getClass()) return false;
    Book b = (Book) o;
    return title.equals(b.title) && price == b.price;
}

@Override
public int hashCode() {
    return java.util.Objects.hash(title, price);
}

Métodos que todas as classes herdam de Object: toString(), equals(), hashCode(), getClass().

3 · Herança e composição

public class Vehicle {
    protected String plate;
    public Vehicle(String plate) { this.plate = plate; }
    public double tax() { return 50; }
    @Override public String toString() { return "Vehicle " + plate; }
}

public class Truck extends Vehicle {         // Truck É UM Vehicle
    private double load;
    public Truck(String plate, double load) {
        super(plate);                        // construtor da superclasse: 1.ª instrução
        this.load = load;
    }
    @Override                                // reescrita (overriding): mesma assinatura
    public double tax() { return super.tax() + load * 2; }   // super.metodo() chama a versão da mãe
    @Override public String toString() { return super.toString() + " (truck, " + load + " t)"; }
}
  • Java só tem herança simples de classes (extends uma). Uma classe pode implementar várias interfaces.
  • Os construtores não se herdam. Se não chamares super(...), o Java chama super() sem argumentos (erro se a mãe não o tiver).
  • Ao reescrever um método não podes reduzir a visibilidade (um public não pode passar a private).
  • @Override faz o compilador confirmar que estás mesmo a reescrever (apanha erros de nome).

4 · Polimorfismo, classes abstratas e interfaces

Polimorfismo: uma referência do tipo da superclasse pode apontar para objetos de qualquer subclasse, e o método executado é o do objeto real (ligação dinâmica, decidida em execução).

Vehicle v = new Truck("AA-00-BB", 3);   // OK: um Truck é um Vehicle
System.out.println(v.tax());            // chama Truck.tax() (ligação dinâmica)
// v.getLoad();                         // ERRO de compilação: o tipo da referência é Vehicle
if (v instanceof Truck t) {             // confirmar antes de fazer cast
    System.out.println(t.getLoad());
}
Truck t2 = (Truck) new Vehicle("X");    // compila, mas dá ClassCastException em execução
LigaçãoQuando se decideExemplos
Estáticaem compilaçãométodos static, private, final; sobrecarga (overloading)
Dinâmicaem execuçãométodos reescritos (overriding)

Uma referência de subclasse não pode apontar para um objeto da superclasse: Pepino p = new Vegetal(); não compila.

Classe abstrata vs interface

public abstract class Shape {                  // não se pode fazer new Shape()
    protected String color;
    public Shape(String color) { this.color = color; }
    public abstract double area();             // sem corpo: as subclasses concretas TÊM de implementar
    public String describe() { return color + " shape with area " + area(); }   // método concreto
}

public interface Billable {                    // define uma capacidade
    double price();                            // implicitamente public abstract
    default String priceTag() {                // método default (com corpo)
        return String.format("%.2f €", price());
    }
}

public class Circle extends Shape implements Billable, Comparable<Circle> {
    private double r;
    public Circle(String color, double r) { super(color); this.r = r; }
    @Override public double area() { return Math.PI * r * r; }
    @Override public double price() { return area() * 0.1; }
    @Override public int compareTo(Circle o) { return Double.compare(r, o.r); }
}

people.sort(Comparator.comparing(Person::getCity)
                      .thenComparing(Person::getName));     // dois critérios
people.sort((a, b) -> Double.compare(b.getSalary(), a.getSalary()));   // lambda, decrescente

Uma interface funcional tem exatamente um método abstrato (pode ter @FunctionalInterface). Onde se espera uma, podes passar uma lambda.

@FunctionalInterface
interface InspectionTest<T> {
    boolean inspectAction(T testedValue, T correctValue);
}

static void genericTest(InspectionTest<Double> test, String name, double read, double max) {
    if (test.inspectAction(read, max)) System.out.println("Test " + name + " passed!");
    else System.out.println("Test " + name + " failed!");
}

11 · Streams

Uma stream processa os dados de uma coleção em pipeline: fonte → operações intermédias (devolvem outra stream, são preguiçosas) → uma operação terminal (produz o resultado). Não altera a coleção original e só se percorre uma vez.

IntermédiasTerminais
filter(Predicate), map(Function), mapToInt, sorted(), sorted(Comparator), distinct(), limit(n), skip(n) collect(...), forEach, count(), sum(), average(), max/min(Comparator), anyMatch, allMatch, findFirst(), reduce, toList() 
List<String> nomes = people.stream()
        .filter(p -> p.getAge() >= 18)            // só adultos
        .sorted(Comparator.comparing(Person::getName))
        .map(Person::getName)                     // map transforma com uma Function (não um Comparator)
        .collect(Collectors.toList());

double media = people.stream().mapToInt(Person::getAge).average().orElse(0);
long n = people.stream().filter(p -> p.getCity().equals("Aveiro")).count();

        .collect(Collectors.groupingBy(Person::getCity));

12 · JARs, Maven e sockets

  • JAR: ficheiro zip com as .class e um MANIFEST.MF. jar cfe app.jar Main *.class cria um jar executável (a linha Main-Class: Main no manifest); corre-se com java -jar app.jar.
  • Maven: gere o projeto com o pom.xml (groupId, artifactId, version, dependências). Estrutura src/main/java e src/test/java. Comandos: mvn package (gera o jar em target/), mvn exec:java. Um fat jar (plugin shade) inclui as dependências e indica a Main-Class.
  • Sockets: comunicação em rede como se fosse um ficheiro. Servidor: ServerSocket ss = new ServerSocket(5000); Socket s = ss.accept();. Cliente: new Socket("localhost", 5000). Lê-se e escreve-se com s.getInputStream()/getOutputStream() (envolvidos em Scanner/PrintWriter).

Concert.java
public class Concert {
    public static final DateTimeFormatter FMT = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm");
    private static int nextId = 1;          // contador partilhado por todos os concertos

    private final int id;
    private double duration;                // minutos
    private String location;                // "Cidade, País"
    private LocalDateTime start;

    public Concert(double duration, String location, LocalDateTime start) {
        this(nextId, duration, location, start);        // id automático
    }

    public Concert(int id, double duration, String location, LocalDateTime start) {
        this.id = id;                                    // id vindo do ficheiro
        this.duration = duration;
        this.location = location;
        this.start = start;
        if (id >= nextId) nextId = id + 1;               // nota #3: contador acima do maior id
    }

    public int getId() { return id; }
    public double getDuration() { return duration; }
    public void setDuration(double duration) { this.duration = duration; }
    public String getLocation() { return location; }
    public void setLocation(String location) { this.location = location; }
    public LocalDateTime getStart() { return start; }
    public void setStart(LocalDateTime start) { this.start = start; }

    public String getCountry() {                        // texto depois da última vírgula
        String[] parts = location.split(",");
        return parts[parts.length - 1].trim();
    }

    @Override
    public String toString() {
        return String.format("Concert #%d: %s, %s, %.1f min", id, location, start.format(FMT), duration);
    }
}
IConcertProfitCalculator e StandardConcertProfitCalculator
public interface IConcertProfitCalculator {
    double calculateConcertProfit(Concert c);
}

public class StandardConcertProfitCalculator implements IConcertProfitCalculator {
    @Override
    public double calculateConcertProfit(Concert c) {
        double profit = 1500 * (c.getDuration() / 60.0);
        String country = c.getCountry();
        if (!country.equalsIgnoreCase("Portugal")) {
            profit *= 2;                                   // fora de Portugal
        }
        if (!country.equalsIgnoreCase("Portugal") && !country.equalsIgnoreCase("Espanha")) {
            profit -= 800;                                 // fora da península ibérica (repara no &&)
        }
        return profit;
    }
}
ConcertManager.java
public class ConcertManager {
    private Map<Integer, Concert> concerts = new TreeMap<>();      // id -> concerto, ordenado por id
    private IConcertProfitCalculator calculator = new StandardConcertProfitCalculator();

    public void addConcert(Concert c) { concerts.put(c.getId(), c); }   // id repetido: substitui
    public void removeConcert(int id) { concerts.remove(id); }
    public Concert getConcert(int id) { return concerts.get(id); }      // null se não existir

    public double calculateConcertProfit(int id) {
        Concert c = concerts.get(id);
        if (c == null) return -1;
        return calculator.calculateConcertProfit(c);
    }

    public void printAllConcerts() {
        for (Concert c : concerts.values()) System.out.println(c);
    }

    public void sortConcertsByProfit() {                // por mês; dentro do mês, lucro decrescente
        Map<Integer, List<Concert>> byMonth = new TreeMap<>();
        for (Concert c : concerts.values()) {
            int month = c.getStart().getMonthValue();
            byMonth.putIfAbsent(month, new ArrayList<>());
            byMonth.get(month).add(c);
        }
        for (Map.Entry<Integer, List<Concert>> e : byMonth.entrySet()) {
            List<Concert> list = e.getValue();
            list.sort((a, b) -> Double.compare(calculator.calculateConcertProfit(b),
                                               calculator.calculateConcertProfit(a)));
            System.out.println("Mês " + e.getKey() + ":");
            for (Concert c : list)
                System.out.printf("  %s -> %.2f €%n", c, calculator.calculateConcertProfit(c));
        }
    }

    public void readFile(String fich) {
        try (Scanner sc = new Scanner(new File(fich))) {
            while (sc.hasNextLine()) {
                String line = sc.nextLine().trim();
                if (line.isEmpty() || line.startsWith("ID")) continue;   // cabeçalho
                String[] f = line.split(";");
                int id = Integer.parseInt(f[0].trim());
                double duration = Double.parseDouble(f[1].trim());
                String location = f[2].trim();                           // "Aveiro, Portugal" (a vírgula não estraga o split por ;)
                LocalDateTime start = LocalDateTime.parse(f[3].trim(), Concert.FMT);
                addConcert(new Concert(id, duration, location, start));  // nota #2: substitui se existir
            }
        } catch (FileNotFoundException e) {
            System.out.println("Ficheiro não encontrado: " + fich);
        }
    }

    public void writeFile(String fich) {
        try (PrintWriter pw = new PrintWriter(fich)) {
            for (Concert c : concerts.values()) {
                pw.printf("%d;%.1f;%s;%s;%.2f%n", c.getId(), c.getDuration(), c.getLocation(),
                          c.getStart().format(Concert.FMT), calculator.calculateConcertProfit(c));
            }
        } catch (FileNotFoundException e) {
            System.out.println("Erro ao escrever " + fich);
        }
    }
}

Erros clássicos

Que dão erro ou pontos perdidos

  • Comparar Strings com == (usa equals).
  • Condições com != ligadas por || que são sempre verdadeiras.
  • Atributo de objeto não inicializado → NullPointerException.
  • Remover de uma lista dentro de um for-each → ConcurrentModificationException.
  • nextInt() seguido de nextLine() devolve linha vazia.
  • Redefinir equals sem hashCode (HashSet deixa de funcionar).
  • catch (Exception e) antes de exceções mais específicas.

De desenho

  • Atributos public (perde-se o encapsulamento).
  • Usar herança onde é composição ("tem um", não "é um").
  • Declarar pelo tipo concreto (ArrayList<X> l) em vez da interface.
  • Guardar datas como String em vez de LocalDate.
  • Esquecer o toString (os testes imprimem os objetos).
  • Não testar no main todas as funcionalidades pedidas.
