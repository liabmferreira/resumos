2 · Tautologias, Contradições e Equivalências
Tautologia (válida)

Verdadeira em todas as interpretações.

p ∨ ¬p ← sempre verdade
Consistente

Verdadeira em alguma interpretação.

p ∧ q ← v. quando p=q=1
Contradição (inconsistente)

Falsa em todas as interpretações.

p ∧ ¬p ← nunca verdade
Equivalência

φ ≡ ψ quando φ ↔ ψ é tautologia (valores de verdade iguais em toda a interpretação).

Equivalências Fundamentais — MEMORIZAR

Comutatividade: (p∧q) ≡ (q∧p) (p∨q) ≡ (q∨p) Associatividade: (p∧q)∧r ≡ p∧(q∧r) (p∨q)∨r ≡ p∨(q∨r) Idempotência: p∧p ≡ p p∨p ≡ p Identidade: p∧⊤ ≡ p p∨⊥ ≡ p Dominação: p∧⊥ ≡ ⊥ p∨⊤ ≡ ⊤ De Morgan: ¬(p∨q) ≡ ¬p∧¬q ¬(p∧q) ≡ ¬p∨¬q Implicação: (p→q) ≡ ¬p∨q Contraposição: (p→q) ≡ (¬q→¬p) Dupla negação: ¬¬p ≡ p Distributividade: p∧(q∨r) ≡ (p∧q)∨(p∧r) p∨(q∧r) ≡ (p∨q)∧(p∨r)
⚠️Consequência semântica: φ₁,...,φₙ |= ψ significa que em toda a interpretação onde φ₁,...,φₙ são verdadeiras, ψ também é verdadeira. Equivalente a: {φ₁,...,φₙ,¬ψ} é inconsistente.

3 · Formas Normais (CNF e DNF)
Literal

Uma variável (p) ou a sua negação (¬p).

CNF — Forma Normal Conjuntiva

Conjunção de cláusulas. Cada cláusula é disjunção de literais.

(p∨q) ∧ (¬p∨r) ∧ (¬r)

← 3 cláusulas em conjunção

DNF — Forma Normal Disjuntiva

Disjunção de cláusulas. Cada cláusula é conjunção de literais.

(p∧q) ∨ (¬p∧r) ∨ (¬r)

← 3 cláusulas em disjunção

Como Obter a CNF — Algoritmo

  1. Eliminar ↔: φ↔ψ ≡ (φ→ψ)∧(ψ→φ)
  2. Eliminar →: φ→ψ ≡ ¬φ∨ψ
  3. Mover ¬ para dentro (De Morgan): ¬(φ∨ψ) ≡ ¬φ∧¬ψ e ¬(φ∧ψ) ≡ ¬φ∨¬ψ, ¬¬φ ≡ φ
  4. Distribuir ∨ sobre ∧: φ∨(ψ∧θ) ≡ (φ∨ψ)∧(φ∨θ)
Exemplo
Fórmula: ¬(p→q) Passo 1: ¬(¬p∨q) (eliminar →) Passo 2: ¬¬p ∧ ¬q (De Morgan) Passo 3: p ∧ ¬q (dupla negação) ← já é CNF (e DNF!)

4 · Método de Resolução (Proposicional)
⚡ Estratégia de Resolução
  1. Converter φ₁,...,φₙ para CNF
  2. Negar ψ e converter ¬ψ para CNF
  3. Aplicar a regra de resolução repetidamente
  4. Se obtemos ⊥ → demonstrado. Se não há mais resolventes sem ⊥ → não se verifica
Regra de Resolução

5 · Lógica de 1ª Ordem — Sintaxe

A lógica de 1ª ordem permite expressar propriedades sobre objetos num domínio, usando quantificadores:

Quantificador Universal
∀x φ "para todo x, φ"

Ex: ∀x (gato(x) → garras(x))

Quantificador Existencial
∃x φ "existe x tal que φ"

Ex: ∃y amigo(y, Ana)

Componentes de um Alfabeto de 1ª Ordem

TipoExemplosDescrição
Variáveisx, y, zRepresentam elementos do domínio
ConstantesAna, 0, aDenotam elementos fixos
Funçõesf(x), +(x,y), pai(x)Mapeiam n argumentos a 1 resultado
PredicadosP(x), gato(x), <(x,y)Relações — verdadeiras ou falsas

Termos e Fórmulas (definição recursiva)

Termos
  • Variável ou constante → termo
  • Se f é função de n argumentos e t₁,...,tₙ são termos → f(t₁,...,tₙ) é termo
Fórmulas
  • P(t₁,...,tₙ) com predicado P e termos tᵢ → fórmula (átomo)
  • t₁ = t₂ → fórmula
  • ⊤, ⊥ → fórmulas
  • Se φ,ψ são fórmulas → ¬φ, φ∧ψ, φ∨ψ, φ→ψ são fórmulas
  • Se φ é fórmula e x variável → ∀x φ e ∃x φ são fórmulas

6 · Semântica de 1ª Ordem
Variável Ligada

Ocorrência dentro do alcance de um quantificador dessa variável.

∀x (gato(x) → garras(x)) ↑ x ocorre ligada
Variável Livre

Ocorrência NÃO dentro do alcance do quantificador.

(∀x x < y) ∧ (a < x) ↑ x livre aqui

Uma fórmula fechada não tem variáveis livres.

Prenex e Skolemestudado ✓

7 · Formas Normais de 1ª Ordem
Forma Normal Prenex

Todos os quantificadores no início: Qx₁...Qxₙ φ onde φ é sem quantificadores.

Para obter:

  • ¬∀x φ ≡ ∃x ¬φ
  • ¬∃x φ ≡ ∀x ¬φ
  • Mover quantificadores para fora
Forma Normal de Skolem

∀x₁...∀xₙ φ com φ em CNF (sem quantificadores).

Eliminar ∃:

  • ∃x φ → substituir x por nova constante c
  • ∀x₁...∀xₖ₋₁ ∃xₖ φ → substituir xₖ por f(x₁,...,xₖ₋₁) (nova função)
Exemplo de Skolemização
¬∃x (B(x)∧¬S(x)) ≡ ∀x (¬B(x)∨S(x)) ← já está em forma de Skolem ∃x (P(x)∧B(x)) ⟝ P(c)∧B(c) ← c é nova constante de Skolem Cláusulas: {P(c)}, {B(c)}
⚠️{φ₁,...,φₙ} é consistente se e só se as suas skolemizações {ψ₁,...,ψₙ} são consistentes.

Algoritmo de Unificação Mais Geralestudado ✓

8 · Unificação — Encontrar o mgu
Substituição

σ = {t₁/v₁,...,tₙ/vₙ} substitui cada variável vᵢ pelo termo tᵢ. Escrevemos Eσ para aplicar σ à expressão E.

Unificador Mais Geral (mgu)

Um unificador σ de E = {E₁,...,Eₙ} tal que E₁σ = E₂σ = ... = Eₙσ e todo o outro unificador θ = λ △ σ para algum λ.

Algoritmo do mgu — Passo a Passo

  1. Começar: k=0, E₀=E, σ₀=ε (substituição identidade)
  2. Se Eₖ tem apenas 1 expressão → σₖ é o mgu, PARAR
  3. Determinar Dₖ = conjunto das diferenças (primeiras sub-expressões onde as expressões divergem)
  4. Se existe variável v e termo t em Dₖ e v NÃO ocorre em t → σₖ₊₁ = {t/v} △ σₖ, Eₖ₊₁ = Eₖ{t/v}, k++, voltar a 2
  5. Caso contrário → NÃO É UNIFICÁVEL
🔴Condição de ocorrência: Se v ocorre em t (ex: v=x, t=f(x)) → NÃO é unificável! (f(x)≠x para nenhuma substituição)
Exemplo: E = {P(y,z), P(x,h(y)), P(A,h(A))}
D₀ = {y, x, A} → σ₁ = {x/y}, E₁ = {P(x,z), P(x,h(x)), P(A,h(A))} D₁ = {x, A} → σ₂ = {A/x,A/y}, E₂ = {P(A,z), P(A,h(A)), P(A,h(A))} D₂ = {z, h(A)} → σ₃ = {h(A)/z,A/x,A/y}, E₃ = {P(A,h(A))} mgu = {A/x, A/y, h(A)/z} ✓

9 · Resolução de 1ª Ordem

Regras da Resolução de 1ª Ordem

RESOLVENTE BINÁRIA: ¬ψ ∨ θ φ ∨ γ (sem variáveis comuns!) ─────────────────────── BR (θ ∨ γ) · mgu(ψ, φ) FATOR: φ ∨ ψ ∨ θ ────────────────── Fator (φ ∨ θ) · mgu(φ, ψ)

Procedimento Completo

  1. Converter {φ₁,...,φₙ, ¬ψ} para Forma Normal de Skolem
  2. Ignorar quantificadores ∀ (todas as variáveis estão universalmente quantificadas)
  3. Renomear variáveis em cada cláusula para serem distintas
  4. Aplicar Resolvente Binária e Fator até obter ⊥
Exemplo Clássico (Lewis Carroll) — Porquinhos e Beethoven
Hipóteses em cláusulas: ¬B(x) ∨ S(x) (quem aprecia Beethoven mantém silêncio) ¬P(y) ∨ I(y) (porquinhos são ignorantes) ¬I(z) ∨ ¬S(z) (ignorantes não mantêm silêncio) P(c), B(c) (skolemização de ∃x P(x)∧B(x)) Dedução: 1. P(c) (Hip) 2. ¬P(y)∨I(y) (Hip) 3. I(c) (BR 1,2: mgu={c/y}) 4. ¬I(z)∨¬S(z) (Hip) 5. ¬S(c) (BR 3,4: mgu={c/z}) 6. ¬B(x)∨S(x) (Hip) 7. ¬B(c) (BR 5,6: mgu={c/x}) 8. B(c) (Hip) 9. ⊥ (BR 7,8) ✓

  • Calcular mgu entre dois predicados e aplicar à resolvente

10 · Princípio da Gaiola dos Pombos
🐦 Princípio dos Pombos

Se n pombos voam para m gaiolas e n > m, então pelo menos uma gaiola tem mais do que um pombo.

Se f: A → B e |A| > |B|, então f NÃO é injetiva (existem x₁≠x₂ com f(x₁)=f(x₂))

Generalização: Se km < |A| e f: A→B com |B|=m, então existem k+1 elementos de A com a mesma imagem.

Exemplos Tipo
  • Meses: Num grupo >12 pessoas, duas fazem anos no mesmo mês.
  • Sala 7×7: 50 pessoas numa sala 7×7 → existe um quadrado 1×1 com 2 pessoas a distância ≤ √2 < 1,5m
  • Cabelos: Max. 200 000 fios → com 2 870 208 pessoas, existem ≥15 com o mesmo número

Princípio

Se existe uma bijeção f: A → B entre conjuntos finitos, então |A| = |B|.

Usar quando é mais fácil contar B do que A.

Princípio da Adição

Conjuntos A₁,...,Aₙ dois a dois disjuntos:

|A₁ ∪ ... ∪ Aₙ| = |A₁| + ... + |Aₙ|

13 · Inclusão-Exclusão
Fórmula Geral |A₁∪...∪Aₙ| = Σ|Aᵢ| − Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩Aₖ| − ... + (−1)ⁿ⁺¹|A₁∩...∩Aₙ| Para 2 conjuntos: |A₁∪A₂| = |A₁| + |A₂| − |A₁∩A₂| Para 3 conjuntos: |A₁∪A₂∪A₃| = |A₁|+|A₂|+|A₃| − |A₁∩A₂|−|A₁∩A₃|−|A₂∩A₃| + |A₁∩A₂∩A₃|
Exemplo — Números entre 1 e 1000 divisíveis por 3 ou 5
|A₃| = ⌊1000/3⌋ = 333 |A₅| = ⌊1000/5⌋ = 200 |A₃∩A₅| = |A₁₅| = ⌊1000/15⌋ = 66 |A₃∪A₅| = 333 + 200 − 66 = 467
💡Nenhuma das propriedades: |X \ (A₁∪...∪Aₙ)| = |X| − |A₁∪...∪Aₙ| (complemento)

14 · Arranjos

Arranjos COM Repetição

Escolher k elementos de n com repetição e com ordem:

Ar(n,k) = nᵏ

Ex: Sequências binárias de comprimento n = Ar(2,n) = 2ⁿ

Arranjos SEM Repetição

Escolher k elementos de n sem repetição, com ordem (função injetiva):

As(n,k) = n·(n−1)·...·(n−k+1) = n!/(n−k)!

Caso especial n=k: As(n,n) = n! (permutações)

Exemplos
  • Números de 4 algarismos com dígitos 1..9: Ar(9,4) = 9⁴ = 6561
  • Números de 4 algarismos distintos: As(9,4) = 9·8·7·6 = 3024
  • Sentar k pessoas de n num banco corrido: As(n,k)
  • Sentar k pessoas de n numa mesa redonda: As(n,k)/k

15 · Combinações

Combinações SEM Repetição

Subconjuntos de k elementos de n (sem repetição, sem ordem):

C(n,k) = (n k) = As(n,k)/k! = n!/((n−k)!·k!)

Combinações COM Repetição

Multiconjuntos de k elementos de n (com repetição, sem ordem):

Cr(n,k) = ((n k)) = C(n+k−1, k) = C(n+k−1, n−1)

= Soluções de x₁+...+xₙ=k com xᵢ∈N

Tabela Resumo │ COM repetição │ SEM repetição ────────────┼──────────────────────┼──────────────────────── COM ordem │ Ar(n,k) = nᵏ │ As(n,k) = n!/(n−k)! (arranjos) │ │ ────────────┼──────────────────────┼──────────────────────── SEM ordem │ Cr(n,k) = C(n+k−1,k)│ C(n,k) = n!/(k!(n−k)!) (combinações)│ │

Propriedades dos Coeficientes Binomiais

C(n,0) = C(n,n) = 1 C(n,k) = C(n, n−k) ← simetria C(n,k) = C(n−1,k−1) + C(n−1,k) ← triângulo de Pascal Σₖ C(n,k) = 2ⁿ ← soma linha Pascal (a+b)ⁿ = Σₖ C(n,k)·aᵏ·bⁿ⁻ᵏ ← fórmula binomial de Newton
Exemplos Tipo
  • Comprar 3 bilhetes de 6 tipos diferentes: C(6,3) = 20
  • Grupo de 16♀ e 15♂, grupos de 5 com ≥3♂: C(15,3)·C(16,2) + C(15,4)·C(16,1) + C(15,5) = 79443
  • 20 bolas indistinguíveis em 5 caixas, ≥2 cada: colocar 2 em cada → distribuir 10 em 5 → Cr(5,10) = C(14,4) = 1001

16 · Permutações com Repetição e Coeficiente Multinomial
Teorema — Permutações com Repetição

Número de permutações do multiconjunto {x₁ⁿ¹,...,xₖⁿᵏ} de tamanho n = n₁+...+nₖ:

n! / (n₁! · n₂! · ... · nₖ!)
Coeficiente Multinomial
C(n; n₁,n₂,...,nₖ) = n! / (n₁!·n₂!·...·nₖ!) = número de sequências de k subconjuntos disjuntos com tamanhos n₁,...,nₖ

Fórmula Multinomial: (a₁+...+aₖ)ⁿ = Σ C(n;n₁,...,nₖ) · a₁ⁿ¹·...·aₖⁿᵏ

Exemplo — Números de telefone
Telefone com 2 dois, 4 três, 2 seis, 1 nove (8 dígitos livres): = 8! / (1!·4!·2!·1!) = 40320 / 48 = 840

18 · Noções Gerais
Definição

Uma equação de recorrência de ordem k é uma equação da forma xₙ = f(n, xₙ₋₁, ..., xₙ₋ₖ). Uma solução é uma sucessão (aₙ)ₙ∈ℕ que satisfaz a equação para todo o n ≥ k.

Exemplos Clássicos

  • Torre de Hanói: a₁=1, aₙ=2aₙ₋₁+1 → solução: aₙ = 2ⁿ−1 → a₆₄ ≈ 1,8×10¹⁹
  • Fibonacci: F₀=1, F₁=1, Fₙ=Fₙ₋₁+Fₙ₋₂ → Fₙ = (φⁿ⁺¹−ψⁿ⁺¹)/√5 (fórmula de Binet)
  • Factorial: a₀=1, aₙ₊₁=(n+1)aₙ → aₙ=n!
Teorema Fundamental

Soluções de xₙ = c₁xₙ₋₁+...+cₖxₙ₋ₖ+dₙ = solução particular + todas as soluções da equação homogénea associada.

19 · Equações Lineares Homogéneas
⚡ Algoritmo — Raízes Distintas
  1. Escrever a equação caraterística: 0 = qᵏ − c₁qᵏ⁻¹ − ... − cₖ
  2. Encontrar as k raízes distintas q₁,...,qₖ
  3. Solução geral: (C₁q₁ⁿ + C₂q₂ⁿ + ... + Cₖqₖⁿ)ₙ∈ℕ
  4. Determinar C₁,...,Cₖ pelas condições iniciais (sistema de k equações)
Exemplo — xₙ = xₙ₋₁ + 2xₙ₋₂, x₀=5, x₁=4
Eq. caraterística: q²−q−2 = (q−2)(q+1) = 0 → q₁=2, q₂=−1 Solução geral: aₙ = α·2ⁿ + β·(−1)ⁿ Condições iniciais: n=0: α + β = 5 n=1: 2α − β = 4 Somar: 3α = 9 → α=3, β=2 Solução: aₙ = 3·2ⁿ + 2·(−1)ⁿ ✓

28 · Conexidade e Teorema de Euler
Conexidade
  • Vértices u,v são conexos se existe caminho entre eles
  • Grafo G é conexo se todos os pares de vértices são conexos
  • cc(G) = número de componentes conexas
  • Aresta ponte: a sua remoção aumenta cc(G) (não pertence a nenhum ciclo)
Teorema de Euler — Circuito

Grafo G finito e conexo tem circuito de Euler (passa por todas as arestas) ↔ todos os vértices têm grau par.

Teorema de Euler — Trajeto

Grafo G finito e conexo tem trajeto de Euler ↔ o número de vértices de grau ímpar é 0 ou 2.

⚠️Pontes de Königsberg: Os vértices têm graus 3, 5, 3, 3 — todos ímpares (4 vértices de grau ímpar) → Não existe trajeto de Euler → Não é possível cruzar todas as pontes uma só vez!
Grafos Bipartidos

G é bipartido (V=X∪Y, arestas só entre X e Y) ↔ G não tem ciclos de comprimento ímpar.

Caminho de Custo Mínimoestudado ✓

30 · Algoritmo de Dijkstra
⚡ Algoritmo de Dijkstra

Input: grafo com custos W(u,v)≥0, vértice inicial start.

  1. Inicializar: marca(v)=∞ para todo v; marca(start)=0; temp=V\{start}; menor=start
  2. Para cada v em temp: se marca(v) > marca(menor)+W(menor,v) → atualizar marca(v) e ant(v)=menor
  3. Remover de temp o vértice vaux com menor marca; menor=vaux
  4. Repetir até menor=vértice final

Resultado: marca(v) = custo do caminho mínimo de start a v. Reconstruir caminho via ant(v).

Exemplo — Grafo 1→2(W=1), 1→3(W=3), 2→3(W=1), 3→4(W=1), 2→4(W=3)
Passo 0: marca={1:0, 2:∞, 3:∞, 4:∞}, temp={2,3,4}, menor=1 Passo 1 (menor=1): marca(2)=0+1=1, marca(3)=0+3=3 → menor=2 Passo 2 (menor=2): marca(3)=min(3,1+1)=2, marca(4)=min(∞,1+3)=4 → menor=3 Passo 3 (menor=3): marca(4)=min(4,2+1)=3 → menor=4 Caminho mínimo 1→4: custo=3, percurso 1→2→3→4

31 · Árvores e Florestas
Floresta

Grafo simples sem ciclos.

Árvore

Floresta conexa (floresta com uma só componente).

Caracterizações Equivalentes de Árvore (Teorema)

As seguintes afirmações são equivalentes para G simples com ≥1 vértice:

  • (i) G é uma árvore
  • (ii) Entre cada par de vértices existe um único caminho
  • (iii) G é conexo e cada aresta é uma ponte (minimamente conexo)
  • (iv) G não tem ciclos e acrescentar uma aresta cria um ciclo (maximalmente acíclico)

Propriedades Numéricas

Árvore com n vértices tem exatamente n−1 arestas. Floresta: ε(G) = ν(G) − cc(G) Cada árvore com ≥2 vértices tem pelo menos 2 folhas (vértices de grau 1). τ(G) = número de árvores abrangentes.
Fórmula de Cayley
τ(Kₙ) = nⁿ⁻² = número de árvores etiquetadas com n vértices

Código de Prüfer — Bijeção com Sequências

Codificação (pruefer):

  1. Encontrar menor folha v
  2. Registar o único vizinho de v
  3. Remover v
  4. Repetir n−2 vezes

Decodificação (unpruefer):

  1. Dado P=(a₁,...,aₙ₋₂) e L=vértices ordenados
  2. Menor em L não em P → ligar ao a₁; remover ambos
  3. Repetir até restar 2
Propriedade: v aparece d(v)−1 vezes no código. Folha ↔ não aparece no código. |{sequências de comprimento n−2}| = nⁿ⁻² = |{árvores com V}|
Fórmula recursiva: τ(G) = τ(G−a) + τ(G//a) (G−a = remover aresta a; G//a = contrair aresta a, fundir extremos)

Algoritmos de Kruskal e Primestudado ✓

32 · Árvores Abrangentes de Custo Mínimo

Algoritmo de Kruskal

  1. Ordenar arestas por custo crescente
  2. E'=∅
  3. Para cada aresta (por ordem): adicionar a E' SE não cria ciclo
  4. Parar quando T=(V,E') é conexo

Estratégia: escolher arestas mais baratas sem criar ciclos.

Algoritmo de Prim

  1. Escolher vértice inicial u
  2. V'={u}, E'=∅
  3. Enquanto V'≠V: adicionar a aresta mais barata entre V' e V\V'

Estratégia: crescer uma árvore a partir de um vértice.

Exemplo Kruskal
Ordenar arestas: eg(5), fg(5), de(6), ef(7), ad(7), ce(8), df(8), ab(9), be(9), bc(11), bd(15) (riscar arestas que criam ciclos) Selecionar: eg, fg (espera...) ad, ce, df, ab, be, eg → T com custo 39
