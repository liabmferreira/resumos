1. Medição e incertezaestudado ✓

Bibliografia: Guião da disciplina · Serway, cap. 1 e apêndice B.8 · Sørenssen, cap. 3

A Física procura identificar leis fundamentais que governam os fenómenos naturais. Está baseada em observações experimentais e medições quantitativas. A análise dos dados medidos fornece relações matemáticas entre as quantidades medidas. Há um ciclo central que atravessa toda a disciplina:

Conceito central

Fenómeno → Medição → Modelação → Previsão → (de novo) Fenómeno. Medimos um fenómeno, construímos um modelo matemático que o descreve, usamos esse modelo para prever comportamentos não observados, e testamos essa previsão de novo no fenómeno real.

Toda a medição requer: instrumentos de medição, padrões de medida, e um sistema de unidades (com conversão entre unidades). Uma medida sem unidade não tem significado.

Todas as outras grandezas (velocidade, aceleração, força, energia...) derivam destas.

Conversão de unidades

Exemplo clássico: \(v = 60\) km/h em m/s:

\[ v = 60 \frac{\text{km}}{\text{h}} = 60 \times \frac{1000\,\text{m}}{3600\,\text{s}} = 60 \times 0.27777\ldots\ \text{m/s} = 16.67\ \text{m/s} \]

Como reportar um resultado

O valor de qualquer medição está sempre afetado por uma incerteza: \(c = \bar{c} \pm \Delta c\).

  • Erros de leitura — limitação do instrumento.
    • Escala digital: o erro é uma divisão da escala.
    • Escala contínua: o erro é metade da menor divisão.
  • Erros de observação — limitações em observar o fenómeno, variação aleatória do processo, erro humano.
Exemplo

Ao medir o comprimento de um lápis, se temos a certeza que \(4.0\,\text{cm} < c < 4.5\,\text{cm}\), então: melhor estimativa \(\bar c = 4.25\) cm e incerteza \(\Delta c = 0.25\) cm. Reporta-se \( c = 4.3 \pm 0.3 \) cm — a melhor estimativa arredondada à mesma casa decimal da incerteza, e a incerteza com 1 algarismo significativo.

Precisão vs. Exatidão

\[ \text{erro absoluto} = \Delta c \qquad \text{erro relativo} = \frac{\Delta c}{\bar c} \]
  • Precisão: grau de variação da medição — maior precisão ⇔ erro relativo menor.
  • Exatidão: proximidade do valor medido ao valor correto.

São conceitos diferentes: é possível ter alta precisão mas baixa exatidão se houver um erro sistemático (os valores medidos não refletem corretamente o valor real, embora sejam consistentes entre si).

Erros numéricos (em cálculo computacional)

Surgem porque: as operações têm precisão limitada; o algoritmo pode ser apenas aproximado; pode haver erros de implementação (bugs). Estes erros acumulam-se ao longo do cálculo.

2. Combinação / propagação de errosestudado ✓

Regras de propagação

Soma ou subtração — somam-se os erros absolutos:

\[ S = L + P \quad\Rightarrow\quad \Delta S = \Delta L + \Delta P \] \[ D = L - P \quad\Rightarrow\quad \Delta D = \Delta L + \Delta P \]

Produto ou divisão — somam-se os erros relativos:

\[ A = L \times P \quad\Rightarrow\quad \frac{\Delta A}{A} = \frac{\Delta L}{L} + \frac{\Delta P}{P} \]

Caso geral — \(F = F(x,y,\ldots)\):

\[ \Delta F = \left|\frac{\partial F}{\partial x}\right|\Delta x + \left|\frac{\partial F}{\partial y}\right|\Delta y + \cdots \]

Medições repetidas

Em geral o erro em cada medição é aleatório. Repetindo a medição podemos melhorar a precisão:

  • A melhor estimativa é a média das medições.
  • O desvio padrão \(\sigma\) indica a variação em cada medição individual.
  • O erro na média diminui com o número de medições: \( s = \sigma/\sqrt{N} \).

3. Modelação e regressão linearestudado ✓

Modelar significa construir um conjunto de equações matemáticas capazes de representar com exatidão os fenómenos em estudo — para codificar leis observadas, prever comportamento em condições não observadas, e simular fenómenos não observados.

Exemplo motivador — difração

Numa experiência de difração, mede-se a distância \(L\) (fenda ao alvo) e \(X\) (distância entre máximos). Os dados, colocados num gráfico, parecem indicar uma relação linear entre \(L\) e \(X\). Como extrair a reta que melhor representa os dados?

Método dos mínimos quadrados

Dados experimentais \((x_i, y_i)\); pontos da reta-modelo \((x_i, p_i)\) com \(p_i = mx_i + b\) (não se conhecem \(m\) e \(b\)). Minimiza-se a soma dos quadrados dos desvios:

\[ S(m,b) = \sum_{i=1}^{N} (y_i - p_i)^2 \]

Impondo \(\partial S/\partial m = 0\) e \(\partial S/\partial b = 0\) obtém-se:

\[ m = \frac{N\sum x_i y_i - \sum x_i \sum y_i}{N\sum x_i^2 - \left(\sum x_i\right)^2} \qquad b = \frac{\sum x_i^2 \sum y_i - \sum x_i \sum x_i y_i}{N\sum x_i^2 - \left(\sum x_i\right)^2} \]

O coeficiente de determinação \(r^2\) avalia a qualidade do ajuste (\(r^2 \approx 1\): ótimo ajuste; \(r^2 \approx 0\): modelo não é linear). Os erros associados a \(m\) e \(b\) também podem ser calculados a partir de \(r^2\), \(N\) e dos \(x_i\).

4. Linearização, leis de potência, exponenciais e polinómiosestudado ✓

Lei de potência \(y = c\,x^n\)

Aplicando logaritmos:

\[ \log_b y = \log_b c + n \log_b x \]

É uma reta no gráfico \(\log y\) vs \(\log x\): declive = \(n\) (a potência).

Lei exponencial \(y = y_0 e^{\lambda t}\) \[ \log_b y = \log_b y_0 + \lambda t \]

Reta no gráfico \(\log y\) vs \(t\): declive = \(\lambda\) (pode ser positivo ou negativo).

Linearização geral: se conhecermos a forma \(y^m = cx^n + b\), fazendo \(Y = y^m\) e \(X = x^n\), obtém-se \(Y = cX + b\), uma reta (com \(m, n\) possivelmente negativos).

Interpolação vs. extrapolação

  • Interpolação — prever dentro do intervalo medido. Maior confiança.
  • Extrapolação — prever fora do intervalo medido. Menor confiança: o modelo pode não ser válido nessa região (não há medições próximas que confirmem).

Polinómios e a escolha do modelo

Python: np.polyfit(x,y,n) ajusta um polinómio de grau \(n\) (com \(n=1\) é o ajuste linear); desvantagem: não calcula diretamente \(r^2\) nem os erros dos coeficientes.

Cuidado conceptual

Um polinómio de grau \(n\) ajusta-se perfeitamente ao mesmo número \(n\) de pontos experimentais — isso não o torna automaticamente um bom modelo! Se a relação for realmente linear, o afastamento dos pontos da reta deve-se a erro de medição. Um polinómio de grau elevado pode parecer melhor na interpolação mas dar resultados completamente diferentes (e absurdos) na extrapolação. Usa sempre o grau mínimo necessário.

Casos mais complexos (funções periódicas, distribuições "estranhas" como a radiação do corpo negro de Planck) exigem modelos não lineares específicos, vistos mais tarde na disciplina.

1. Posição, velocidade e aceleraçãoestudado ✓

Cinemática, integração numérica, método de Euler

Definições \[ v(t) = \frac{dx}{dt} \qquad a(t) = \frac{dv}{dt} = \frac{d^2x}{dt^2} \]

Velocidade média: \(\bar v = \dfrac{\Delta x}{\Delta t}\). Velocidade instantânea é o limite quando \(\Delta t \to 0\) — o declive da tangente ao gráfico \(x(t)\). Aceleração é o declive da tangente a \(v(t)\).

Em sentido inverso: dada \(a(t)\), integrando obtemos \(v(t)\); integrando \(v(t)\) obtemos \(x(t)\).

2. Movimento com aceleração constanteestudado ✓

Equações do movimento uniformemente acelerado \[ v(t) = v_0 + at \] \[ x(t) = x_0 + v_0 t + \tfrac{1}{2}at^2 \] \[ v^2 = v_0^2 + 2a(x-x_0) \]

Caso particular importante: queda livre, \(a = -g \approx -9.8\ \text{m/s}^2\) (eixo positivo para cima).

3. Movimento com aceleração não constanteestudado ✓

Quando \(a(t)\) não é constante (ex: força dependente da velocidade, como resistência do ar), as fórmulas anteriores deixam de ser válidas — é necessário integrar:

\[ v(t) = v_0 + \int_0^t a(t')\,dt' \qquad x(t) = x_0 + \int_0^t v(t')\,dt' \]

Nem sempre estes integrais têm solução analítica simples — daí a necessidade de métodos numéricos.

4. Método de Eulerestudado ✓

Ideia: discretizar o tempo em passos pequenos \(\Delta t = h\), e aproximar a derivada pela diferença finita:

\[ \frac{dx}{dt} \approx \frac{x(t+h)-x(t)}{h} \quad\Rightarrow\quad x(t+h) \approx x(t) + h\,v(t) \]
Algoritmo de Euler (atualização passo a passo) \[ v_{i+1} = v_i + a_i\,h \] \[ x_{i+1} = x_i + v_i\,h \]

Repete-se a partir de condições iniciais \(x_0, v_0\), calculando \(a_i\) em cada passo a partir da física do problema (segunda lei de Newton: \(a_i = F(x_i,v_i,t_i)/m\)).

Pseudocódigo / Python 
x = x0; v = v0; t = 0
while t < t_final:
    a = calcula_aceleracao(x, v, t)
    v = v + a*h
    x = x + v*h
    t = t + h

Nota importante: a ordem importa — no Euler "simples" (Euler-Cromer, ver Cap. 3) o uso da velocidade já atualizada \(v_{i+1}\) para atualizar \(x\) costuma dar melhores resultados que o Euler "puro" (que usa \(v_i\)).

5. Erro de truncatura e escolha do passo \(h\)estudado ✓

O método de Euler é uma aproximação de 1ª ordem: o erro local por passo é proporcional a \(h^2\) (da expansão em série de Taylor), e o erro acumulado ao longo da simulação é proporcional a \(h\).

Compromisso (trade-off)
  • \(h\) pequeno → menor erro de truncatura, mas mais passos → mais tempo de cálculo e maior acumulação de erros de arredondamento (numéricos).
  • \(h\) grande → cálculo mais rápido, mas erro de truncatura maior — a simulação pode divergir do comportamento físico real.

Na prática, testa-se a convergência da solução: diminui-se \(h\) sucessivamente e compara-se o resultado; quando deixa de mudar significativamente, \(h\) é suficientemente pequeno.

Sumário do Capítulo 2
  • \(v = dx/dt\), \(a = dv/dt\): a cinemática é um problema de derivadas/integrais.
  • Com \(a\) constante usam-se as equações clássicas do MRUA.
  • Com \(a\) variável é necessário integrar numericamente — Método de Euler.
  • Euler: \(v_{i+1}=v_i+a_i h\), \(x_{i+1}=x_i+v_i h\) (ou \(v_{i+1}\) no caso de Euler-Cromer).
  • Erro de truncatura \(\propto h\); passo menor = mais exato mas mais lento.

1. Álgebra de vetoresestudado ✓

Vetores, tipos de força, Leis de Newton, Euler-Cromer em 2D/3D

Em 2D/3D as quantidades cinemáticas são vetores: posição \(\vec r\), velocidade \(\vec v = d\vec r/dt\), aceleração \(\vec a = d\vec v/dt\). Cada componente (x, y, z) pode ser tratada independentemente.

Operações fundamentais \[ \vec A + \vec B = (A_x+B_x,\, A_y+B_y,\, A_z+B_z) \] \[ |\vec A| = \sqrt{A_x^2+A_y^2+A_z^2} \] \[ \vec A \cdot \vec B = A_xB_x+A_yB_y+A_zB_z = |\vec A||\vec B|\cos\theta \] \[ \hat A = \frac{\vec A}{|\vec A|}\ \ \text{(vetor unitário, direção de } \vec A\text{)} \]

O produto escalar é usado para projeções e trabalho (Cap. 4); o produto vetorial \(\vec A \times \vec B\) é usado para torque/momento angular (perpendicular ao plano de \(\vec A,\vec B\), módulo \(|\vec A||\vec B|\sin\theta\)).

3. Leis de Newtonestudado ✓

1ª Lei (Inércia)

Um corpo permanece em repouso ou em movimento retilíneo uniforme a não ser que uma força resultante atue sobre ele. Válida em referenciais inerciais.

2ª Lei (Fundamental da Dinâmica) \[ \sum \vec F = m\vec a \quad\Leftrightarrow\quad \vec a = \frac{\sum \vec F}{m} \]

Relaciona a força resultante com a aceleração — é a equação central usada para construir simulações numéricas: a partir de \(\sum\vec F\) calculamos \(\vec a\), e depois integramos (Euler/Euler-Cromer) para obter \(\vec v(t)\) e \(\vec r(t)\).

3ª Lei (Ação-Reação) \[ \vec F_{A\to B} = -\vec F_{B\to A} \]

Forças surgem sempre em pares: se A exerce uma força sobre B, B exerce uma força igual e oposta sobre A (atuam em corpos diferentes, por isso não se anulam).

Diagrama de corpo livre

Estratégia geral para resolver problemas: isolar o corpo, desenhar todas as forças que atuam sobre ele, escolher um referencial conveniente (eixos), decompor cada força nas componentes desse referencial, e aplicar \(\sum F_x = ma_x\), \(\sum F_y = ma_y\) separadamente.

4. Movimento em 2D/3D — exemplos clássicosestudado ✓

Movimento de projétil (sem resistência do ar)

Aceleração constante \(\vec a = (0,-g)\). As componentes \(x\) e \(y\) são independentes:

\[ x(t) = x_0 + v_{0x}t \qquad y(t) = y_0 + v_{0y}t - \tfrac12 g t^2 \]

Trajetória parabólica. Com resistência do ar (dependente de \(v\)), as componentes deixam de ser independentes (o módulo de \(\vec v\) entra nas duas equações) → necessário recorrer a Euler-Cromer.

Sistema Terra-Sol (órbitas, gravitação universal)

Força gravítica como função vetorial da posição relativa:

\[ \vec a = -\frac{GM}{r^2}\hat r \]

É um problema clássico de simulação: não existe solução analítica trivial em coordenadas cartesianas para o caso geral, por isso recorre-se à integração numérica passo a passo. Permite obter órbitas elípticas (Leis de Kepler) a partir da 2ª Lei de Newton + Lei da Gravitação.

5. Método de Euler-Cromer (2D/3D)estudado ✓

Generalização vetorial do método de Euler do Cap. 2, aplicado a cada componente:

Algoritmo de Euler-Cromer \[ \vec a_i = \frac{\sum \vec F(\vec r_i,\vec v_i,t_i)}{m} \] \[ \vec v_{i+1} = \vec v_i + \vec a_i\,h \] \[ \vec r_{i+1} = \vec r_i + \vec v_{i+1}\,h \quad \text{(usa-se a velocidade já atualizada!)} \]
Porquê "Cromer" e não Euler puro?

O Euler-Cromer (usar \(v_{i+1}\) em vez de \(v_i\) para atualizar a posição) conserva muito melhor a energia em sistemas oscilatórios/orbitais ao longo de muitos passos — o Euler puro tende a "ganhar" energia artificialmente e a órbita diverge (espiral para fora). É por isso o método preferido nestas simulações.

1. Trabalho e Teorema Trabalho-Energiaestudado ✓

Trabalho, energia, forças conservativas, integração numérica, momento linear, colisões

Trabalho de uma força \[ W = \int_{\vec r_1}^{\vec r_2} \vec F \cdot d\vec r \]

Para força constante e deslocamento retilíneo: \(W = \vec F\cdot\vec d = Fd\cos\theta\).

Teorema Trabalho-Energia Cinética \[ W_{\text{total}} = \Delta K = K_f - K_i \qquad K = \tfrac12 mv^2 \]

O trabalho realizado pela força resultante é igual à variação de energia cinética.

2. Forças conservativas e energia potencialestudado ✓

Uma força é conservativa se o trabalho que realiza entre dois pontos não depende do caminho percorrido (só dos pontos inicial e final). Para essas forças define-se uma energia potencial \(U\):

\[ W_{\text{cons}} = -\Delta U \qquad F = -\frac{dU}{dx} \]
ForçaEnergia potencial
Gravítica (perto da superfície): \(F=-mg\)\(U = mgy\)
Gravitação universal: \(F=-GMm/r^2\)\(U = -GMm/r\)
Elástica (mola): \(F=-kx\)\(U = \tfrac12 kx^2\)
Conservação da Energia Mecânica \[ E = K + U = \text{constante} \quad \text{(quando só atuam forças conservativas)} \]

Forças não-conservativas (atrito, resistência do ar) dissipam energia mecânica (transformam-na em calor): \(\Delta E = W_{\text{não-cons}}\).

3. Integração numérica do trabalhoestudado ✓

Quando \(\vec F\) não é constante (ex: mola, gravitação, arrasto), calcular \(W=\int \vec F\cdot d\vec r\) analiticamente pode ser difícil ou impossível — usa-se integração numérica.

Regra do trapézio (e Simpson) \[ \int_a^b f(x)\,dx \approx \sum_{i} \frac{f(x_i)+f(x_{i+1})}{2}\,\Delta x \]

Aproxima a área sob a curva por uma soma de trapézios (em vez de retângulos, como no Euler simples) — dá maior precisão. Existem regras de ordem ainda mais alta (Simpson) usadas no cálculo computacional da disciplina.

Em simulações de dinâmica (Euler-Cromer), a energia pode ser calculada a cada passo somando \(K_i\) e \(U_i\); isto serve como teste de validação: se \(E\) se mantém aproximadamente constante (sem forças dissipativas), a simulação está correta.

4. Potênciaestudado ✓

\[ P = \frac{dW}{dt} = \vec F\cdot\vec v \qquad \text{(unidade SI: watt, W = J/s)} \]

Mede a taxa a que o trabalho é realizado (ou energia transferida) por unidade de tempo.

5. Momento linear e colisõesestudado ✓

Momento linear e 2ª Lei de Newton (forma geral) \[ \vec p = m\vec v \qquad \sum \vec F = \frac{d\vec p}{dt} \]

Para sistemas de partículas: o momento total \(\vec P = \sum_i m_i \vec v_i\) só muda devido a forças externas ao sistema — forças internas (entre partículas do sistema) cancelam-se aos pares (3ª Lei de Newton).

Conservação do Momento Linear \[ \text{se } \sum \vec F_{\text{ext}} = 0 \quad\Rightarrow\quad \vec P = \text{constante} \]

Aplica-se tipicamente a colisões (a duração é curta, as forças internas dominam): o momento total antes = momento total depois.

Colisão 1D elástica — equações resultantes

Com massas \(m_1,m_2\) e velocidades iniciais \(v_{1i}, v_{2i}\), resolvendo simultaneamente conservação do momento e da energia cinética obtém-se:

\[ v_{1f} = \frac{m_1-m_2}{m_1+m_2}v_{1i} + \frac{2m_2}{m_1+m_2}v_{2i} \] \[ v_{2f} = \frac{2m_1}{m_1+m_2}v_{1i} + \frac{m_2-m_1}{m_1+m_2}v_{2i} \]

Centro de massa

\[ \vec r_{cm} = \frac{\sum_i m_i \vec r_i}{\sum_i m_i} \qquad \vec v_{cm} = \frac{\vec P}{M_{\text{total}}} \]

O centro de massa de um sistema isolado move-se com velocidade constante (consequência direta da conservação do momento), mesmo que as partículas individuais colidam ou interajam entre si.

1. Oscilador Harmónico Simples (OHS)estudado ✓

Oscilador Harmónico Simples, amortecido, forçado, ressonância, circuitos RLC, caos, Runge-Kutta

Sistema clássico: massa \(m\) presa a uma mola de constante \(k\) (Lei de Hooke), sem atrito. A força restauradora é proporcional ao deslocamento e de sentido oposto:

Equação de movimento \[ F = -kx = ma = m\ddot x \quad\Rightarrow\quad \ddot x + \omega_0^2 x = 0, \qquad \omega_0 = \sqrt{\frac{k}{m}} \]
Solução geral \[ x(t) = A\cos(\omega_0 t + \phi) \]

\(A\) — amplitude (determinada pelas condições iniciais); \(\omega_0\) — frequência angular natural (rad/s), depende apenas de \(k\) e \(m\) (não da amplitude!); \(\phi\) — fase inicial.

\[ T = \frac{2\pi}{\omega_0} \qquad f = \frac{1}{T} = \frac{\omega_0}{2\pi} \]

\(T\) — período (s); \(f\) — frequência (Hz).

Velocidade e aceleração: \(v(t) = -A\omega_0\sin(\omega_0 t+\phi)\), \(a(t) = -A\omega_0^2\cos(\omega_0 t+\phi) = -\omega_0^2 x(t)\).

2. Energia e espaço de faseestudado ✓

Energia do OHS \[ E = K+U = \tfrac12 mv^2 + \tfrac12 kx^2 = \tfrac12 kA^2 = \text{constante} \]

A energia total é constante e proporcional ao quadrado da amplitude — oscila entre cinética (máxima no centro, \(x=0\)) e potencial (máxima nos extremos, \(x=\pm A\)).

Espaço de fase (\(x\) vs. \(v\)): para o OHS sem atrito, a trajetória no espaço de fase é uma elipse fechada (ou círculo, com escalas adequadas) — reflete a conservação de energia. À medida que o sistema perde energia (amortecimento), a trajetória espirala para dentro.

3. Interpolação de Lagrangeestudado ✓

Ferramenta matemática usada para estimar o valor de uma função entre pontos conhecidos (por exemplo, para encontrar com precisão o instante em que \(x(t)=0\) numa simulação numérica, sem precisar de \(h\) extremamente pequeno). Dado um conjunto de pontos \((x_i,y_i)\), o polinómio interpolador de Lagrange é:

\[ P(x) = \sum_{i} y_i \prod_{j\ne i} \frac{x-x_j}{x_i-x_j} \]

Para 3 pontos (interpolação quadrática) é o caso mais usado nesta disciplina, por exemplo para refinar a estimativa do período de oscilação a partir de pontos discretos da simulação.

4. Oscilador Harmónico Amortecidoestudado ✓

Adiciona-se uma força de amortecimento proporcional à velocidade (ex: atrito viscoso): \(F_{\text{am}} = -b\dot x\).

Equação de movimento \[ m\ddot x + b\dot x + kx = 0 \quad\Leftrightarrow\quad \ddot x + 2\beta\dot x + \omega_0^2 x = 0,\qquad \beta=\frac{b}{2m} \]

Criticamente amortecido\(\beta = \omega_0\)regressa ao equilíbrio o mais rápido possível, sem oscilar

A energia decai exponencialmente: \(E(t) \propto e^{-2\beta t}\). O fator de qualidade \(Q = \omega_0/(2\beta)\) mede quão pouco amortecido é o sistema (Q alto = oscila muitas vezes antes de parar).

5. Oscilador Forçado e Ressonânciaestudado ✓

Adiciona-se uma força externa periódica: \(F_{\text{ext}}(t) = F_0\cos(\omega t)\), com \(\omega\) a frequência de excitação (pode ser diferente de \(\omega_0\)).

Equação de movimento \[ m\ddot x + b\dot x + kx = F_0\cos(\omega t) \]

A solução tem duas partes: o transitório (decai com o tempo, depende das condições iniciais, igual à solução do amortecido livre) e o regime estacionário (sobrevive, oscila à frequência de excitação \(\omega\), não \(\omega_0\)):

\[ x_{\text{est}}(t) = A(\omega)\cos(\omega t - \delta) \] \[ A(\omega) = \frac{F_0/m}{\sqrt{(\omega_0^2-\omega^2)^2 + (2\beta\omega)^2}} \]
Ressonância

A amplitude \(A(\omega)\) é máxima quando \(\omega\) está próximo de \(\omega_0\) (a frequência natural do sistema) — fenómeno de ressonância. Quanto menor o amortecimento \(\beta\), mais estreito e mais alto é o pico de ressonância (maior amplitude máxima).

\[ \omega_{\text{res}} = \sqrt{\omega_0^2 - 2\beta^2} \]

Exemplos físicos: ponte de Tacoma Narrows, copo de cristal partido por uma nota musical, sintonização de rádio (circuito RLC ressonante), absorção de luz por átomos/moléculas.

7. Osciladores não-harmónicos e Caosestudado ✓

Quando a força restauradora não é exatamente linear (ex: pêndulo para amplitudes grandes, onde \(\sin\theta \ne \theta\)), o sistema deixa de ser um OHS perfeito:

  • O período passa a depender da amplitude (ao contrário do OHS, onde \(T\) é independente de \(A\)).
  • A forma de onda \(x(t)\) deixa de ser uma sinusoide pura (contém harmónicos — ver Fourier, Cap. 6).
Caos determinístico

Certos osciladores não-lineares forçados e amortecidos (ex: pêndulo forçado com amplitude grande) exibem comportamento caótico: apesar de o sistema ser completamente determinístico (sem aleatoriedade nas equações), o movimento torna-se imprevisível a longo prazo, e é extremamente sensível às condições iniciais — duas trajetórias com condições iniciais quase idênticas divergem exponencialmente ("efeito borboleta"). Visualiza-se através de diagramas de espaço de fase e secções de Poincaré, onde trajetórias caóticas preenchem regiões em vez de seguirem curvas fechadas simples.

8. Método de Runge-Kutta de 4ª ordem (RK4)estudado ✓

O método de Euler tem erro de truncatura \(\propto h\) (1ª ordem) — para simulações longas ou que exigem maior precisão (oscilações ao longo de muitos períodos, sistemas caóticos sensíveis), usa-se o Runge-Kutta de 4ª ordem, com erro \(\propto h^4\) — muito mais preciso para o mesmo \(h\).

Ideia do RK4 (para \(\dot y = f(y,t)\)) \[ k_1 = f(y_i, t_i) \] \[ k_2 = f(y_i + \tfrac{h}{2}k_1,\ t_i+\tfrac{h}{2}) \] \[ k_3 = f(y_i + \tfrac{h}{2}k_2,\ t_i+\tfrac{h}{2}) \] \[ k_4 = f(y_i + h k_3,\ t_i+h) \] \[ y_{i+1} = y_i + \frac{h}{6}(k_1+2k_2+2k_3+k_4) \]

Em vez de usar só o declive no início do intervalo (Euler), o RK4 calcula 4 estimativas do declive (início, duas no meio, fim) e faz uma média ponderada — daí a precisão muito maior. Em Python normalmente usa-se scipy.integrate.odeint ou solve_ivp, que implementam RK4/RK45 internamente.

Sumário do Capítulo 5
  • OHS: \(\ddot x+\omega_0^2x=0\), \(x(t)=A\cos(\omega_0t+\phi)\), \(\omega_0=\sqrt{k/m}\) — independente da amplitude.
  • Energia do OHS é constante: \(E=\tfrac12kA^2\); espaço de fase é uma elipse fechada.
  • Amortecido: \(\ddot x+2\beta\dot x+\omega_0^2x=0\) — regimes sub/crítico/sobre-amortecido; energia decai exponencialmente.
  • Forçado: regime estacionário oscila à frequência de excitação \(\omega\); amplitude máxima perto de \(\omega\approx\omega_0\) → ressonância.
  • Circuito RLC é matematicamente análogo ao oscilador mecânico amortecido forçado.
  • Não-linearidades alteram o período com a amplitude e podem gerar caos determinístico.
  • RK4 tem erro \(\propto h^4\), muito mais preciso que Euler (\(\propto h\)) para simulações longas.

1. Dois osciladores acopladosestudado ✓

2 e 3 osciladores acoplados, modos normais (método matricial), batimento, série de Fourier, N osciladores, equação de onda, sinais e digitalização

Dois corpos A e B, cada um ligado a uma parede por uma mola de constante \(k\), e ligados entre si por uma mola de acoplamento de constante \(k'\). Definindo os desvios às posições de equilíbrio \(u_A = x_A-x_{Aeq}\) e \(u_B = x_B-x_{Beq}\), a 2ª Lei de Newton dá um sistema de equações acopladas (a equação de A contém \(u_B\) e vice-versa):

Equações de movimento \[ m\ddot u_A = -k\,u_A - k'(u_A-u_B) \] \[ m\ddot u_B = -k\,u_B + k'(u_A-u_B) \]

Resolvendo numericamente (Euler-Cromer), o movimento geral não é periódico de forma simples — mas para certas condições iniciais especiais aparecem soluções sinusoidais puras, os modos normais:

ModoCondição inicialFrequênciaPadrão de movimento
Modo normal 1\(u_A=u_B\) (mesmo lado)\(\omega_1=\sqrt{k/m}\)A mola de acoplamento não se deforma; os dois corpos oscilam em fase
Modo normal 2\(u_A=-u_B\) (espelho)\(\omega_2=\sqrt{(k+2k')/m}\)Os corpos oscilam em oposição de fase
Solução geral (sobreposição dos modos normais) \[ x_A(t) = x_{Aeq} + A_1\cos(\omega_1 t+\phi_1) + A_2\cos(\omega_2 t+\phi_2) \] \[ x_B(t) = x_{Beq} + A_1\cos(\omega_1 t+\phi_1) - A_2\cos(\omega_2 t+\phi_2) \]

As constantes \(A_1,A_2,\phi_1,\phi_2\) determinam-se a partir das 4 condições iniciais (\(x_{A0},x_{B0},v_{A0},v_{B0}\)), resolvendo um sistema de 4 equações a 4 incógnitas.

Ideia central

Qualquer movimento de 2 corpos acoplados por interação elástica é uma sobreposição dos modos normais. Um movimento aparentemente não periódico é, na realidade, a soma de dois movimentos harmónicos simples de frequências diferentes \(\omega_1\) e \(\omega_2\).

Acoplamento fraco e batimento

Quando \(k'\ll k\), as frequências \(\omega_1\) e \(\omega_2\) ficam muito próximas. A solução pode escrever-se como produto de cossenos de frequência "rápida" (média) e "lenta" (diferença) — fenómeno de batimento:

\[ x_A(t) = x_{Aeq} + 2A_1\cos(\omega_{\text{rap.}}t)\cos(\omega_{\text{lent.}}t), \qquad \omega_{\text{rap.}}=\frac{\omega_1+\omega_2}{2},\quad \omega_{\text{lent.}}=\frac{\omega_2-\omega_1}{2} \]

Visualmente: uma oscilação rápida cuja amplitude é modulada lentamente. A energia transfere-se alternadamente de um oscilador para o outro.

Acoplados, amortecidos e forçados

Adicionando amortecimento (\(-b v\)) os dois osciladores tendem para o equilíbrio. Adicionando uma força externa periódica num dos corpos, cada oscilador tende para um regime estacionário harmónico simples, com ressonância sempre que a frequência da força externa coincide com uma das frequências dos modos normais (\(\omega_1\) ou \(\omega_2\)) — generalização do conceito de ressonância do Cap. 5 a sistemas com vários graus de liberdade.

2. Série de Fourierestudado ✓

Ferramenta de análise de frequências: qualquer função periódica \(f(t)\), de período \(T\) e frequência angular \(\omega=2\pi/T\), pode ser decomposta numa soma de senos e cossenos de frequência múltipla de \(\omega\):

Série de Fourier \[ f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \big(a_n\cos\omega_n t + b_n\sin\omega_n t\big), \qquad \omega_n = n\omega \] \[ a_n = \frac{2}{T}\int_0^T f(t)\cos\omega_n t \,dt \qquad b_n = \frac{2}{T}\int_0^T f(t)\sin\omega_n t \,dt \]

Quando os dados estão representados por pontos discretos (como numa simulação numérica), os integrais calculam-se por integração numérica trapezoidal, varrendo um intervalo de um período completo entre dois índices de tempo \(it_0\) e \(it_1\).

Aplicação: identificar modos normais

Calculando os coeficientes de Fourier do movimento simulado de um sistema de osciladores acoplados, aparecem picos nítidos exatamente nas frequências dos modos normais (\(\omega_1\) e \(\omega_2\)). Isto confirma, por análise espectral, que qualquer movimento do sistema é de facto uma sobreposição desses modos — mesmo quando, no domínio do tempo, o movimento não parece periódico.

Para um oscilador não-harmónico (ex: potencial quártico \(E_p=\alpha x^4\)) forçado, o espectro de Fourier não apresenta uma frequência característica única, refletindo a ausência de periodicidade simples típica de sistemas não-lineares.

3. Modos normais — método matricial (N corpos)estudado ✓

Para sistemas com mais de 2 corpos (ex: 3 osciladores acoplados A–B–C por molas \(k,k',k'\)), procurar os modos normais por tentativa-e-erro deixa de ser prático. Usa-se um método geral baseado em valores e vetores próprios.

Experimentando uma solução sinusoidal \(u_i(t)=A_i\cos(\omega t+\alpha)\) para cada corpo \(i\) e substituindo nas equações de Newton (\(\ddot u_i \to -\omega^2 u_i\)), obtém-se um sistema linear homogéneo que, em forma matricial, é um problema de valores próprios:

Problema de valores próprios \[ \mathbf{M}\,\vec u = \omega^2\,\vec u \]

onde \(\mathbf{M}\) é a "matriz dinâmica" do sistema (construída a partir de \(k,k',m\)). Os valores próprios \(\omega_i^2\) são os quadrados das frequências dos modos normais; os vetores próprios correspondentes indicam o padrão relativo de deslocamento de cada corpo nesse modo (e são ortogonais entre si).

Princípio geral: o número de modos normais é igual ao número de massas (graus de liberdade) do sistema. Qualquer dinâmica do sistema é uma sobreposição dos seus modos normais, com a combinação específica (amplitudes e fases) determinada pelas condições iniciais — confirmável por análise de Fourier do movimento simulado.

Aplicação física: os modos normais descrevem vibrações de moléculas, cristais e sólidos. Excitando a matéria com luz laser (que exerce força elétrica sobre núcleos atómicos carregados), obtém-se ressonância quando a frequência do laser coincide com um modo normal — técnica usada para determinar a constituição química e estrutural de materiais e gases.

4. N osciladores acopladosestudado ✓

Generalização a uma cadeia de \(N\) massas iguais \(m\) ligadas por molas idênticas de constante \(k\). A equação de Newton para a massa \(i\) envolve apenas os vizinhos imediatos:

Equação de movimento da massa \(i\) \[ m\ddot u_i = k(u_{i+1}-u_i) - k(u_i-u_{i-1}) = k(u_{i+1}-2u_i+u_{i-1}) \]

Os modos normais de uma cadeia de N osciladores formam, no espaço (posições de equilíbrio das massas), um padrão sinusoidal: representando os desvios iniciais de cada massa em função da sua posição de equilíbrio, os pontos caem sobre uma curva \(\cos\), com um "comprimento de onda" espacial inversamente proporcional ao número do modo. Este padrão mantém-se para qualquer N.

Movimento geral (modo \(n\)) \[ u_i = A_n\cos(\omega_n t+\phi_{i,n}), \qquad \phi_{i,n} = -c_n x_{i,\text{eq}} \]

\(\omega_n\) — frequência angular do modo \(n\); \(c_n\) — "frequência espacial" do modo (depende de \(k\), \(m\) e da distância entre massas). Cada massa oscila com a mesma frequência \(\omega_n\), mas com uma fase diferente que varia linearmente com a sua posição — o movimento é periódico tanto no tempo como no espaço. O movimento geral é a sobreposição \(u_i=\sum_n A_n\cos(\omega_n t+\phi_{i,n})\); as posições iniciais formam uma série de Fourier parcial no índice espacial \(i\).

Numa cadeia de osciladores acoplados, uma perturbação introduzida numa extremidade propaga-se ao longo da cadeia com velocidade finita (a transmissão de energia e informação não é instantânea) — esta observação motiva diretamente a passagem ao contínuo e à equação de onda.

5. Equação de ondaestudado ✓

Tomando o limite de um número muito grande de osciladores acoplados (\(N\to\infty\)), com posições de equilíbrio espaçadas de \(\delta x\to 0\), massa por unidade de comprimento \(M\) (\(m=M\,\delta x\)) e constante elástica por unidade de comprimento \(K\) (\(k=K/\delta x\)), e expandindo \(u_{i\pm1}\) em série de Taylor em torno de \(u_i\), a equação discreta \(m\ddot u_i = k(u_{i+1}-2u_i+u_{i-1})\) transforma-se, no limite contínuo, na equação de onda:

Equação de onda \[ \frac{\partial^2 u}{\partial t^2} = v^2\frac{\partial^2 u}{\partial x^2}, \qquad v^2=\frac{K}{M}\quad\text{(1D)} \] \[ \frac{\partial^2 u}{\partial t^2} = v^2\left(\frac{\partial^2 u}{\partial x^2}+\frac{\partial^2 u}{\partial y^2}+\frac{\partial^2 u}{\partial z^2}\right)\quad\text{(3D)} \]

\(u(x,t)\) — desvio da posição de equilíbrio no ponto \(x\) e instante \(t\) (longitudinal ou transversal); \(v\) — velocidade de propagação. Aplica-se à propagação do som, ondas no oceano, vibração de uma corda, ondas eletromagnéticas, entre outras.

Cada modo normal de uma cadeia de osciladores corresponde, no limite contínuo, a uma onda sinusoidal \(u(x,t)=A\cos(\omega t - cx)\), que oscila simultaneamente no espaço e no tempo, com \(v=\omega/c\).

Tipo de ondaDireção da perturbação vs. propagação
Longitudinalmesma direção (ex: som)

Solução geral — meio infinito

Para um meio infinito (ex: corda muito comprida), com condição inicial \(u(x,0)=f(x)\), a equação de onda admite como soluções qualquer função da forma \(f(x\mp vt)\) — um perfil que se propaga sem deformar, para a direita ou para a esquerda com velocidade \(v\):

\[ u(x,t) = \tfrac12\big[f(x-vt) + f(x+vt)\big] \]

Princípio de sobreposição: se \(u_1(x,t)\) e \(u_2(x,t)\) são soluções da equação de onda (linear), então \(u_1+u_2\) também é solução — por exemplo, dois pulsos que se cruzam em sentidos opostos somam-se e voltam a separar-se inalterados.

Meio finito — corda fixa nas extremidades

Para uma corda de comprimento \(L\) fixa em ambas as extremidades, \(u(0,t)=u(L,t)=0\). Testando \(u(x,t)=A\sin(kx)\cos(\omega t)\) e substituindo na equação de onda obtém-se \(\omega=kv\); a condição de fronteira em \(x=L\) restringe \(k\) a valores discretos:

Modos normais de vibração de uma corda \[ k = \frac{n\pi}{L} \quad\Rightarrow\quad u_n(x,t) = A\sin\!\Big(\frac{n\pi}{L}x\Big)\cos\!\Big(\frac{n\pi v}{L}t\Big), \qquad n=1,2,3,\dots \]

A solução geral é uma sobreposição de todos os modos normais — formalmente análoga a uma série de Fourier no espaço:

\[ u(x,t) = \sum_{n=1}^{\infty} A_n\sin\!\Big(\frac{n\pi}{L}x\Big)\cos\!\Big(\frac{n\pi v}{L}t\Big) \]

6. Sinais e digitalizaçãoestudado ✓

Um sinal é uma função que varia no espaço e/ou no tempo, usada para transmitir informação (sinal elétrico, ótico, eletromagnético, áudio, etc). Qualquer sinal \(f(t)\) pode ser representado como sobreposição de funções sinusoidais — a série de Fourier — ou, de forma equivalente, em notação complexa:

\[ f(t) = \sum_{n=-\infty}^{\infty} c_n \exp(i\omega_n t), \qquad c_n = \frac{1}{T}\int_0^T f(t)\exp(-i\omega_n t)\,dt \]

Um sinal pode então ser representado de duas formas equivalentes, contendo a mesma informação: no domínio do tempo (a forma de onda \(f(t)\)) ou no domínio da frequência (o espectro \(c(\omega)\)). No limite \(T\to\infty\), os valores discretos \(\omega_n\) tornam-se contínuos — dando origem à Transformada de Fourier.

Teorema de Nyquist (amostragem)

Para representar exatamente um sinal contínuo seriam precisos infinitos coeficientes de Fourier; mas se o sinal não contém frequências acima de \(f\) (ou \(\omega\)), basta amostrá-lo em pontos espaçados de menos de \(\delta t = \pi/\omega\) para o reconstruir completamente:

\[ \delta t < \frac{\pi}{\omega} \qquad\Longleftrightarrow\qquad \omega_{\max} = \frac{\pi}{\delta t} \]
Aplicação: áudio digital

O ouvido humano percebe frequências entre 20 Hz e 20000 Hz. Pelo critério de Nyquist, uma frequência máxima de 20000 Hz exige uma taxa de amostragem de \(\delta t=1/40000\,\text{s}\) — por isso os CDs de áudio e o formato MP3 usam 44100 amostras por segundo, suficiente para capturar o sinal sem perda percetível.

Algoritmo de compressão MP3 (simplificado): (1) amostragem do sinal a 44100 valores/s, com 16–24 bits por canal; (2) Transformada Discreta de Fourier, passando para o domínio das frequências; (3) modelo psicoacústico, eliminando sons inaudíveis e reduzindo seletivamente a resolução; (4) compressão final dos dados. Princípios semelhantes aplicam-se ao processamento e compressão de vídeo e imagem, telecomunicações, reconhecimento de fala e extração de características (feature extraction) em aprendizagem automática.

  • Para N corpos, os modos normais resolvem-se como problema de valores/vetores próprios de uma matriz dinâmica: \(\mathbf{M}\vec u=\omega^2\vec u\); nº de modos = nº de massas.
  • N osciladores acoplados: modos formam padrão sinusoidal no espaço; perturbações propagam-se com velocidade finita ao longo da cadeia.
  • No limite contínuo (N→∞) obtém-se a equação de onda \(\partial^2u/\partial t^2=v^2\,\partial^2u/\partial x^2\); soluções \(f(x\mp vt)\) em meio infinito, modos normais \(\sin(n\pi x/L)\cos(n\pi vt/L)\) numa corda fixa.
  • Sinais representam-se no domínio do tempo ou da frequência (espectro de Fourier); o Teorema de Nyquist define a taxa de amostragem mínima — base da digitalização de áudio, vídeo e telecomunicações.

import numpy as np
g = 9.8

def rk4(acel, r0, v0, dt, tmax, parar=None):
    """Integra r'' = acel(r, v, t) com Runge-Kutta 4. r, v são vetores numpy."""
    r, v, t = np.array(r0, float), np.array(v0, float), 0.0
    T, R, V = [t], [r.copy()], [v.copy()]
    while t < tmax:
        k1r, k1v = v,             acel(r, v, t)
        k2r, k2v = v + dt/2*k1v,  acel(r + dt/2*k1r, v + dt/2*k1v, t + dt/2)
        k3r, k3v = v + dt/2*k2v,  acel(r + dt/2*k2r, v + dt/2*k2v, t + dt/2)
        k4r, k4v = v + dt*k3v,    acel(r + dt*k3r,   v + dt*k3v,   t + dt)
        r = r + dt/6*(k1r + 2*k2r + 2*k3r + k4r)
        v = v + dt/6*(k1v + 2*k2v + 2*k3v + k4v)
        t += dt
        T.append(t); R.append(r.copy()); V.append(v.copy())
        if parar and parar(r, v, t): break
    return np.array(T), np.array(R), np.array(V)

\[ m\ddot x_A = -k x_A + k'(x_B - x_A),\qquad m\ddot x_B = -k x_B - k'(x_B - x_A) \]

(b) Com \(x_A(0) = -x_B(0) = x_0\) excita-se só o modo antissimétrico. Fazendo \(x_B = -x_A\):

\[ m\ddot x_A = -(k + 2k')x_A \;\Rightarrow\; x_A(t) = x_0\cos(\omega_2 t),\ x_B(t) = -x_0\cos(\omega_2 t),\quad \omega_2 = \sqrt{\tfrac{k+2k'}{m}} \]

Os dois oscilam sempre em oposição, com a mesma amplitude e uma única frequência (o modo simétrico, com \(\omega_1 = \sqrt{k/m}\), não aparece).

Computacional I — Oscilador cúbico e análise de Fourier

Enunciado m = 1 kg, \(E_p = \frac12kx^2 + \alpha x^3\), k = 1 N/m, α = 0.05 N/m². (a) Diagrama de energia para x ∈ [−8, 4]; movimento se E < 7 J; e se E > 8 J? (b) Lei do movimento com \(x_0\) = 2.2 m, \(v_0 = 0\); energia mecânica. (c) Análise de Fourier.
Ver resolução

(a) \(E_p' = x + 0.15x^2 = 0\) ⟹ mínimo em x = 0 e máximo em \(x = -k/(3\alpha) = -6.67\) m, com \(E_p = 7.41\) J.

  • E < 7 J (abaixo do máximo): movimento limitado e periódico à volta de x = 0, mas assimétrico (mais longe do lado negativo, onde o poço é mais "aberto").
  • E > 8 J (acima de 7.41 J): o corpo passa por cima do máximo e foge para x → −∞; deixa de oscilar.
k, al, m = 1, 0.05, 1
acel = lambda R, v, t: np.array([(-k*R[0] - 3*al*R[0]**2) / m, 0, 0])
T, R, V = rk4(acel, [2.2, 0, 0], [0, 0, 0], 1e-3, 200)
x = R[:,0]
# período: tempo entre passagens consecutivas por x = 0 a subir
s = np.where((x[:-1] < 0) & (x[1:] >= 0))[0]
P = np.diff(T[s]).mean();  w = 2*np.pi/P
# (c) coeficientes de Fourier num período
i0, i1 = s[0], s[1];  ts, xs = T[i0:i1], x[i0:i1]
for n in range(5):
    a = 2/P*np.trapezoid(xs*np.cos(n*w*ts), ts)   # np.trapz em numpy < 2
    b = 2/P*np.trapezoid(xs*np.sin(n*w*ts), ts)
    print(n, np.hypot(a, b))

(b) \(E = \frac12(2.2)^2 + 0.05(2.2)^3 = 2.95\) J (constante). O corpo oscila entre 2.2 m e −2.88 m, com período T ≈ 6.73 s (ω ≈ 0.933 rad/s, menor que \(\omega_0\) = 1 do harmónico puro).

(c) Amplitudes: \(a_0/2\) ≈ 0.52 (valor médio ≠ 0, porque o movimento é assimétrico), n = 1: 2.53, n = 2: 0.18, n = 3: 0.010, n = 4: 0.0004. Domina a fundamental; aparecem harmónicos (2ω, 3ω…) que decrescem depressa — assinatura de um oscilador não linear.

Computacional II — Oscilador quártico forçado (sensibilidade às condições iniciais)

Enunciado m = 1 kg, \(F = -4\alpha x^3 - bv + F_0\cos(\omega_f t)\), α = 0.15, b = 0.02, \(F_0\) = 7.5 N, \(\omega_f\) = 1 rad/s. (a) Lei do movimento com RK4, \(x_0\) = 2 m, \(v_0\) = 0. (b) Até que instante a lei é única se \(x_0\) = 2.000 ± 0.001 m?
Ver resolução
al, b, F0, wf, m = 0.15, 0.02, 7.5, 1.0, 1
acel = lambda R, v, t: np.array([(-4*al*R[0]**3 - b*v[0] + F0*np.cos(wf*t)) / m, 0, 0])
sol = [rk4(acel, [x0, 0, 0], [0, 0, 0], 1e-3, 200) for x0 in (2.000, 1.999, 2.001)]
x = [s[1][:,0] for s in sol];  T = sol[0][0]
dif = np.maximum(abs(x[0] - x[1]), abs(x[0] - x[2]))
print(T[np.argmax(dif > 0.1)])     # 1.º instante em que se afastam mais de 0.1 m
